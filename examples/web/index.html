Browser capability ladder

Twelve small sites, simplest first. Each one checks itself and reports PASS or FAIL in its title and in a results box, so a failure names the browser feature that is missing. Serve this directory over http (levels 07 and 12 fetch data) and open it at http://localhost:PORT/.

  1. Static page HTML + CSS, no script
  2. DOM scripting create / query / mutate
  3. Events listeners, bubbling, forms
  4. Timers setTimeout, setInterval, rAF, microtasks
  5. External resources link, script src, img
  6. Modern JavaScript ES2015+ feature by feature
  7. fetch and XMLHttpRequest needs http://
  8. Todo app vanilla app + localStorage
  9. Client-side router pushState, popstate, URL
  10. ES modules import / export / import()
  11. React (UMD) unmodified react + react-dom 18
  12. React application bundled JSX app: context, reducer, effects, router, fetch
