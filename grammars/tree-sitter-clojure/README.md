# tree-sitter-clojure

A [tree-sitter](https://tree-sitter.github.io/) grammar for **Clojure**,
written for mep and compiled into it, so `.clj`, `.cljs`, `.cljc`, `.cljd`,
`.edn` and `.bb` files are highlighted, folded and outlined without a
grammar `.so` on the machine. It follows the Clojure reader
(`clojure.lang.LispReader` and the reader reference): the tree is what the
reader reads -- atoms, collections and the reader macros' forms -- and there
is no `defn` node. What a list means is decided by the queries, from its
first symbol, so a library's `defsomething` reads exactly like core's.

Its node names, fields and tree shapes are the ones
[sogaiu/tree-sitter-clojure](https://github.com/sogaiu/tree-sitter-clojure)
0.0.13 established -- the grammar mep loaded dynamically before this one --
so queries and tools written for that grammar work unchanged: the same 35
node types and 11 fields, and the same rule order.

| File | What it is |
|---|---|
| `grammar.js` | the grammar (no external scanner: Clojure's tokens are regular) |
| `src/parser.c`, `src/grammar.json`, `src/node-types.json`, `src/tree_sitter/` | generated by `just clojure-grammar` (mep-ts-generate) -- commit them, don't edit them |
| `queries/highlights.scm` | highlight captures (nvim-treesitter naming) |
| `queries/folds.scm` | fold ranges: every multi-line collection and string |
| `queries/structure.scm` | the structure sidebar's outline: `ns`, `def`/`defonce`, `defn`/`defn-`, `defmacro`, `defmulti`/`defmethod`, `defrecord`/`deftype`, `defprotocol`/`definterface`, `deftest` |
| `test/corpus/*.txt` | corpus cases, run by `mep-ts-corpus-test` |

## The shape of the tree

* Whitespace is not an extra but a child wherever the reader allows it, so
  a prefix owns the form after it: metadata is part of the form it
  annotates (`^:private foo` is one `sym_lit` with a `meta_lit` field), as
  are `'`, `` ` ``, `~`, `~@`, `@`, `#'` and `#_`.
* Symbols and keywords are split at the namespace: `sym_ns`/`sym_name`,
  `kwd_ns`/`kwd_name`; a bare `/` is division, `clojure.core//` its
  qualified name.
* `#_form` is a `dis_expr`, highlighted as a comment.

## How it compares

`just grammar-corpus clojure` collects 1,777 distinct files (386,570 lines)
from the jars of clojure-lsp, babashka, clj-kondo, polylith, jet and cljfmt
(Clojure libraries ship as source: Clojure's own core, ClojureScript's,
rewrite-clj, the clj-kondo analyzers...) and neil's source; identical files
across jars are counted once. Against tree-sitter-clojure 0.0.13 (`just
grammar-diff clojure --old <its src>`): all 1,777 files parse to identical
trees, none with errors. Error recovery on 3,000 damaged copies is the same
(+0.02% bytes in ERROR nodes), and the parser is clean under ASan + UBSan
on the corpus and the damaged copies (`just grammar-fuzz clojure`).

The oracle (`--oracle`) is babashka's edamame reader
(`tools/ts_grammar_diff/clojure_read.clj`), which reads without evaluating:
reader conditionals read for `:clj`, any tag, any `::alias`. On the corpus it rejects only polylith's five `{{mustache}}` templates.

## Known limits (shared with the grammar it replaces)

* The grammar reads more than Clojure accepts (`08`, `\abc`, a keyword
  ending in `:`): a highlighter should not stop at a typo. mep's Clojure
  language server reports those.
* Reader extensions a file installs for itself are not known.
