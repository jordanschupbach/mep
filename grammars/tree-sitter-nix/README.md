# tree-sitter-nix

A [tree-sitter](https://tree-sitter.github.io/) grammar for the **Nix**
expression language, written for mep and compiled into it, so `.nix` files
are highlighted and folded without a grammar `.so` on the machine. It
follows Nix's own lexer and parser (`src/libexpr/lexer.l`, `parser.y`), and
its node names are the established tree-sitter-nix ones, so queries
written for that grammar mostly carry over.

| File | What it is |
|---|---|
| `grammar.js` | the grammar: precedence is layered the way `parser.y` layers it |
| `src/scanner.c` | the hand-written external scanner: string contents and paths |
| `src/parser.c`, `src/grammar.json`, `src/node-types.json`, `src/tree_sitter/` | generated by `just nix-grammar` (mep-ts-generate) -- commit them, don't edit them |
| `queries/highlights.scm` | highlight captures (nvim-treesitter naming) |
| `queries/folds.scm` | fold ranges |
| `queries/structure.scm` | the structure sidebar's outline: functions, attrsets and calls given an attrset, nested |
| `queries/injections.scm` | bash in build phases, `/* lang */ ''...''` strings |
| `test/corpus/*.txt` | corpus cases, run by `mep-ts-corpus-test` |

## Why a scanner

Two parts of Nix need more than one token of context to lex:

* **Paths.** `a/b` is a path, not a division, and so is `./${name}.nix`,
  whose first token has to stop at a `/` only because `${` follows it.
  The scanner claims a path only when Nix's lexer would (`/` followed by a
  path segment or by `${`), so `a // b`, `a/*comment*/` and identifiers
  are left to the generated lexer.
* **String text.** `$` is text unless `{` follows, `$${` is literal text,
  and in a `''` string a single `'` is text while `''` ends it or starts
  one of the `''$`, `'''`, `''\x` escapes.

## Working on it

```sh
just nix-grammar      # regenerate src/parser.c and run the corpus tests
```

Then rebuild mep, which compiles `src/` directly (`ts_nix` in
CMakeLists.txt) and embeds `queries/highlights.scm` / `folds.scm` into a
generated header at configure time (`structure.scm` too). `mep-treesitter-test` checks the
highlights mep paints from them.

A good regression check after changing the grammar is to parse all of
nixpkgs, which should produce no errors:

```sh
find "$(nix eval --raw --impure --expr '(builtins.getFlake "nixpkgs").outPath')" -name '*.nix' > /tmp/nix-files
tree-sitter parse --quiet --stat --paths /tmp/nix-files
```
