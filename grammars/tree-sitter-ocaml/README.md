# tree-sitter-ocaml

A [tree-sitter](https://tree-sitter.github.io/) grammar for **OCaml**
implementations (`.ml`), compiled into mep. Its sibling
`../tree-sitter-ocaml_interface` is the interface dialect (`.mli`). Both are
[tree-sitter/tree-sitter-ocaml](https://github.com/tree-sitter/tree-sitter-ocaml)
0.26.0 (commit `a1c562e73ab787dcc69fdc2e5510c53bbce5364f`, 2026-11-07; MIT,
Copyright (c) 2020 Max Brunsfeld and Pieter Goetschalckx; see `LICENSE`).
`src/parser.c` is regenerated by mep's own generator (`just ocaml-grammar`,
checked byte for byte by `just grammar-generate-check`). Node names, fields
and tree shapes are upstream's, so queries and tools written for it work
unchanged.

## Changes from upstream

* Upstream keeps both grammars in one repository (`grammars/ocaml`,
  `grammars/interface`, sharing `grammars/ocaml/grammar.js` and
  `common/scanner.h`). mep keeps one grammar per directory, so the corpus
  runner and the generator see each on its own: the interface grammar lives in
  `../tree-sitter-ocaml_interface` and extends this directory's `grammar.js`.
* `grammar.js` uses `module.exports =` instead of `export default` (mep's
  generator reads CommonJS); the rules are unchanged.
* `common/scanner.h`: `create()` is declared `create(void)` (mep builds the
  scanner with strict C warnings); `src/scanner.c` includes it.
* The corpus (`test/corpus/`) is upstream's with the `:language(...)`
  attributes removed: the cases that are interface-only moved to
  `../tree-sitter-ocaml_interface/test/corpus/`, the ones for both languages
  are in both. Both corpora pass (`mep-ts-corpus-test ocaml ocaml_interface`).

Before it was compiled in, mep loaded OCaml as an optional dynamic grammar
(`ocaml.so` / `ocaml_interface.so`) with a highlight query in
`src/treesitter_queries.h`; that query is replaced by this directory's.

## Queries

* `queries/highlights.scm` -- upstream's highlight query.
* `queries/folds.scm` -- definitions, `struct`/`sig`/`object` bodies,
  matches and their cases, conditionals, loops, `let ... in`, bracketed
  literals, records and variants, comments, multi-line strings.
* `queries/structure.scm` -- the outline: module-level `let`s (functions and
  values), `val`, `external`, types with their constructors and fields,
  exceptions, modules, module types, classes and methods.

## Users

* highlighting, folding and the outline for `.ml` (`src/treesitter.cpp`);
* mep's OCaml language server, `mep-ocaml-lsp` (`src/ocaml_lsp*.cpp`,
  help/ocaml-lsp.org).
