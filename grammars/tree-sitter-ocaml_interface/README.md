# tree-sitter-ocaml_interface

The [tree-sitter](https://tree-sitter.github.io/) grammar for **OCaml
interfaces** (`.mli`), compiled into mep: upstream
[tree-sitter/tree-sitter-ocaml](https://github.com/tree-sitter/tree-sitter-ocaml)'s
`interface` grammar, 0.26.0 (commit `a1c562e73ab787dcc69fdc2e5510c53bbce5364f`;
MIT, see `LICENSE`). Its `grammar.js` extends `../tree-sitter-ocaml/grammar.js`
with `compilation_unit: $ => optional($._signature)`, exactly as upstream's
does, and its scanner is the shared `../tree-sitter-ocaml/common/scanner.h`.
See `../tree-sitter-ocaml/README.md` for what differs from upstream (only
the layout and the module syntax).

`src/parser.c` is regenerated by `just ocaml-grammar` (mep's generator),
checked by `just grammar-generate-check`. The corpus in `test/corpus/` holds
upstream's interface cases (`mep-ts-corpus-test ocaml_interface`).

## Queries

* `queries/highlights.scm` -- upstream's highlight query (the same file as
  the implementation grammar's).
* `queries/folds.scm` -- specifications, signatures, records, variants,
  comments.
* `queries/structure.scm` -- the outline: `val`, `external`, types with
  their constructors and fields, exceptions, modules, module types, classes
  and method specifications.

## Users

* highlighting, folding and the outline for `.mli` (`src/treesitter.cpp`);
* `mep-ocaml-lsp` (help/ocaml-lsp.org), which reads every `.mli` it resolves
  with this grammar.
