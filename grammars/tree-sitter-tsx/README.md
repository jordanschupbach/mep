# tree-sitter-tsx

mep's grammar for **TSX** (`.tsx`): TypeScript with JSX. It is the TSX
dialect of `../tree-sitter-typescript`, whose `common/define-grammar.js`
and `common/scanner.h` it shares; see that README for how both were
written and compared with the grammars they replace.

| File | What it is |
|---|---|
| `grammar.js` | the TSX dialect of `../tree-sitter-typescript/common/define-grammar.js` |
| `src/scanner.c` | `../tree-sitter-typescript/common/scanner.h` under this grammar's name |
| `src/parser.c`, `src/grammar.json`, `src/node-types.json`, `src/tree_sitter/` | generated by `just tsx-grammar` (or `just typescript-grammar`, which does both) -- commit them, don't edit them |
| `queries/highlights.scm` | empty: `.tsx` is highlighted with TypeScript's query over JavaScript's, its JSX section included |
| `queries/folds.scm` | what `.tsx` folds on top of TypeScript's folds: JSX elements and expressions |
| `test/corpus/*.txt` | corpus cases, run by `mep-ts-corpus-test` |
| `test/known-differences.txt` | the reviewed differences from the old grammar, for `just grammar-diff tsx` |

The outline query is TypeScript's (`../tree-sitter-typescript/queries/structure.scm`).
