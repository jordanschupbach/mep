Context

Turning the API off

Key / commandDoes
<leader>axtoggle all paid API use on or off
<leader>akchange the command that prints your key
:MepAiKeythe same, by name

With the API off, nothing here makes a paid call or even runs your key command. Most routes fall back to Claude Code rather than refusing -- the same text, answered in a pane instead -- and say so when they do:

The API is off, so this went to Claude Code instead (<leader>ax turns the API back on).

Two cannot fall back, and refuse instead. :MepAiReplaceSelection has to put the reply back into the buffer, which an agent answering in a pane cannot do -- it checks before touching your selection, so nothing is deleted. Speech-to-text transcribes rather than chats, so there is nothing to hand over.

The switch lives in Settings and is remembered.

The API key

mep looks in three places, in order, and caches what it finds *in memory for the session only* -- it is never written to disk and never stored in your config, so it cannot land in a dotfile backup or a synced directory.

  1. ANTHROPIC_API_KEY or OPENAI_API_KEY, whichever the provider wants.
  2. mep.ai_api_key_cmd, a command that prints the key.
  3. Failing both, a masked prompt.
lua Copy
mep.ai_api_key_cmd = {'pass', 'show', 'anthropic/api'}

The command runs once, on the first request of the session, and its first line of output is the key. Prefer it to the environment variable: mep's :terminal exports its whole environment to child shells, so a key exported for the editor is also readable by every terminal pane, language server and job mep starts -- and by anything else of yours that can read /proc/<pid>/environ. A command keeps the key wherever you already store secrets and out of the environment entirely.

Which model

lua Copy
mep.ai_provider = 'anthropic'            -- default 'openai'
mep.ai_anthropic_model = 'claude-opus-5' -- the default
mep.ai_model = 'gpt-4o-mini'             -- the OpenAI-side default

mep.ai_base_url points the OpenAI path somewhere else, which is how you run this against a local model -- anything speaking the OpenAI chat completions API will do, and the key can be any non-empty string:

lua Copy
mep.ai_base_url = 'http://localhost:11434/v1'  -- ollama
mep.ai_api_key = 'local'
