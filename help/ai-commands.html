Sending something

CommandSends
:MepAiSenda prompt you type
:MepAiSendBufferthe whole buffer, with a prompt
:MepAiSendSelectionthe Visual selection
:MepAiReplaceSelectionthe selection, replacing it with the reply
:MepAiCancelcancel a request in flight
glsend the buffer

:MepAiReplaceSelection is the one that edits your file: select, ask for a rewrite, and the reply takes the selection's place.

Context

<leader>ai (:MepAiContextPicker) chooses what to include alongside your prompt -- other buffers, files, selections -- so a question about one function can carry the code it depends on.

The API key

mep prompts for an API key when it first needs one and keeps it *in memory for the session only*. It is not written to disk and not stored in your config, so it never lands in a dotfile backup or a synced directory.

Set the usual environment variable before launching mep if you would rather not be prompted.
