Claude Code in a pane

Opening one

<leader>a<CR> (:aiterminal, :aiterm, :MepAiTerminal) splits the current pane and runs Claude Code in a terminal below it, focused.

It is a real terminal, so everything on the Terminals page applies -- including Ctrl-\ Ctrl-n to get back to Normal mode.

What makes it different from a plain terminal

The agent is launched with an appended system prompt explaining that it is running inside this mep window and how to drive it through the mep-agent MCP server. So it can read your buffers, edit them, split panes and run commands, rather than only seeing files on disk.

Every :terminal exports $MEP_AGENT_SOCKET -- this window's own agent socket -- which the MCP server honours ahead of its directory scan. That is what makes the agent land on the window it was launched from even with several mep instances open.

Setting it up

The MCP server is expected to be registered with Claude Code already:

claude mcp add mep-agent -- /path/to/mep/build/native/mep-mcp

Alternatively, point mep at it and it will be passed inline with --mcp-config:

lua Copy
mep.opt.ai_terminal_mcp_server = '/path/to/mep-mcp'

Highlight something, press C

Anything you highlight can become the agent's prompt without copying, pasting or retyping it:

WhereGesture
any text bufferselect in Visual mode, then C
a PDFselect or highlight a passage, then C
over a K answer boxo, to carry that passage on

The passage arrives quoted with where it came from -- notes.py:12-20, or paper.pdf, page 3 -- so the agent can go and read around it rather than seeing a bare fragment. If no agent is running, one is started and the passage is sent as soon as it is ready.

This is the only conversational route, on purpose. It needs no API key, and Claude Code keeps its own history, so a conversation survives closing mep. (There used to be an A that discussed a PDF passage over the API in a sidebar; it billed like K, kept no history, and has been removed.)

A passage is sent as one line, because the agent's prompt treats a newline as submit.

Options

lua Copy
mep.opt.ai_terminal_cmd = {'claude', '--model', 'opus'}  -- default {'claude'}
mep.opt.ai_terminal_share = 0.4        -- the terminal's height fraction
mep.opt.ai_terminal_instructions = ''  -- '' sends no appended prompt
