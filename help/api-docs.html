Documents and formats

What is here

Org, Markdown, HTML, PDF, office, spreadsheet, notebook, image, 3D model and learning-deck bindings -- everything that drives one of mep's document viewers or editors.

This page is generated from mep's own binding table, so it lists what the running editor actually exposes. Call any of these from init.lua, from :lua, or from a mep-lua org block.
