Buffers, text and the cursor

What is here

Reading and changing buffer contents, moving the cursor, the clipboard, folds and undo.

This page is generated from mep's own binding table, so it lists what the running editor actually exposes. Call any of these from init.lua, from :lua, or from a mep-lua org block.
