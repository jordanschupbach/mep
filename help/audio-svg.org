* Audio

A =.wav= file opens as a waveform. It is a view, not an editor: useful for
seeing what is in a file -- where the silence is, whether it clipped --
rather than for changing it.

Notebook and document views use the same decoder for embedded audio.

* SVG and XML

=.svg= opens as a picture in the [[file:images.html][image viewer]], from the file tree or =:e=
alike. =Ctrl-E= swaps the picture for the SVG's source text in the same
buffer, and =Ctrl-V= (or =:SvgViewToggle=) draws it again -- save first,
since the picture is rendered from the file on disk.

=.xml= renders as structured markup, through the same engine that draws
HTML.
