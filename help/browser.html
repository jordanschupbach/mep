It is a live page, not a snapshot

The pane pumps the page's event loop every frame, so timers, requestAnimationFrame, promises, async functions and ES modules all run after load.

A click lands on the DOM node under the pointer as a real click event, with checkbox and submit default actions -- and a cancelled click on a link is not followed. Clicking a text field gives it the keyboard: typing raises input, Enter submits the form, and Esc or Tab leaves the field.

Maths

A page's LaTeX maths is typeset in the pane, with no JavaScript and nothing fetched: the parser pulls $...$, $$...$$, \(...\) and \[...\] spans out of the page's prose -- skipping <script>, <style>, <pre>, <code> and <textarea>, the same list MathJax skips -- and mep's own small TeX engine lays each one out. A span on its own line is centred as display maths; one inside a sentence is set inline with the text.

So a MathJax-targeting page (org-mode's HTML export, most course notes) renders its formulae here even offline, and a page that ships MathJax gets the same result without running it.

Equations are set in a serif with real italics -- variables and lowercase Greek slant, digits, operators and \text runs stand upright -- and an inline fragment sits on the same baseline as the words around it.

It covers superscripts and subscripts (with TeX's own script/scriptscript sizing), \frac, \binom and plain TeX's \over, \sqrt, big operators that grow in display maths and take their limits over and under (\sum, \prod, \lim), \left=/=\right fences that stretch to whatever they wrap, radicals drawn to fit their radicand, accents (\hat, \bar, \vec, \overline), the upright operator names (\sin, \log, \max), \mathrm=/=\mathbf=/=\mathbb and the other font commands, \text with its spaces intact, several hundred symbols, the matrix environments (pmatrix, bmatrix, cases, aligned and friends), the spacing commands (\,=, =\;, \quad), and TeX's own inter-atom spacing and unary-sign rules -- so \int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi} reads as that formula.

It is still not TeX: there is no kerning or italic-correction table, no line breaking inside an expression, no \newcommand, and the rows of an align are set independently rather than aligned to each other. A symbol neither embedded font has a glyph for, and any unknown command, shows its own name rather than vanishing -- so a page using something unsupported is legible rather than silently wrong.

WebKit in the pane (:Browser)

:Browser shows a page with the system's own WebKit -- the engine Safari runs on -- inside the pane, instead of mep's renderer. Everything a real browser does works there: sign-ins, video, the whole of a page's JavaScript, and the sites mep's engine cannot draw yet. With no address it opens a blank page with its address bar ready; otherwise it takes the same targets as :Browse.

On macOS the view is a WKWebView inside mep's own window. On Linux it is WebKitGTK -- the same engine, as GTK 4 ships it -- in mep-webview, a small program built alongside mep when webkitgtk-6.0 and gtk4 are installed, whose window mep adopts into the pane the way an :exec pane adopts any program's. Without it, :Browser falls back to :BrowseExternal's WebKitGTK window shown as an :exec pane.

On macOS mep's own mod1 chords (moving between panes) stay mep's; on Linux the page has every key but Ctrl-\ while it holds the keyboard, as any embedded program does.

While mep has the keyboard: H back, L forward, r reload, o edit the address, i into the page. :BrowserBack, :BrowserForward, :BrowserReload and :BrowserGo <address> do the same from the command line. The address bar takes localhost:8000, :8000/app, example.com, file paths, or anything else as a web search.

The page is a real view over mep's window, so it steps aside while a picker or the which-key popup is up.

Theme colours

Pages are drawn in mep's theme, the way PDFs and :Browse pages are: the page's paper becomes the theme's background, its text the theme's foreground, and its coloured links, buttons and highlights the nearest colour of the theme's palette. A site with a dark mode of its own is asked for it when the theme is dark. Images and video keep their colours, and so does text over a picture. :colorscheme re-themes open pages straight away.

Key / commandDoes
Ctrl-Rthe page's own colours, or the theme's again
:BrowserThemethe same
:BrowserTheme on/offset it

The address bar always takes the theme's colours.
