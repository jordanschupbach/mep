C and C++ mode

Opening it

<leader>lu in a C or C++ file. The panels here are built around compiling rather than around a session, because that is what the language gives you.

The panels

PanelShows
Assemblythe compiler's output for the current file
Buildthe build's diagnostics
Hexa hex view of a compiled binary
Helpman for the symbol under the cursor

Assembly

The Assembly panel compiles the current file and shows the generated assembly -- the "what did the compiler actually do with this" view, without leaving the editor.

It uses the same compiler and flags as the run button, taken from the same per-project configuration, so what you see is what your build produces rather than a default-flags approximation.

lua Copy
mep.opt.c_ui_filter_directives = true   -- hide .cfi/.size and friends

Assembler directives are noise for most reading, so filtering them is usually what you want.

Hex

A paged hex dump of a binary.

KeyDoes
nnext page
pprevious page

lua Copy
mep.opt.c_ui_hex_page = 1024   -- bytes per page
