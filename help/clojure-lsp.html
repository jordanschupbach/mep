The Clojure language server

What it is

Clojure files get a language server of their own, mep-clojure-lsp, built and shipped with mep. Open a .clj, .cljs, .cljc, .cljd, .edn or .bb file and it attaches by itself -- nothing to install, *no JVM is started and nothing is evaluated*. It reads the file with mep's own Clojure reader and knows clojure.core and the namespaces that ship with Clojure (clojure.string, clojure.set, clojure.walk, ...) from a table generated from Clojure itself: every var's arglists, docstring, the version it was added in, and whether it is deprecated or private.

On start it indexes the workspace's .clj, .cljc, .cljs and .bb files -- each one's namespace and vars, with their arglists and docstrings -- so definition, hover, completion after alias/ and argument counts reach across files. An open file is re-indexed as you type.

The same binary is a command-line linter; see Linting from the command line below.

The same read errors as Clojure

Its reader errors are the ones the JVM's reader raises, worded the same way, at the same place: the reader is checked against Clojure's own (clojure.core/read with reader conditionals allowed) on 4,755 files -- the 1,777 files of mep's Clojure corpus (Clojure's and ClojureScript's own source, clj-kondo, clojure-lsp, babashka, rewrite-clj...) and damaged copies of them -- and agrees on 4,754. That covers unmatched and unclosed delimiters, bad numbers and tokens (08, 1.2.3, \abc), string and character escapes, regexes, metadata, nested #(), ##Inf-style values, namespaced maps, a map with an odd number of forms or a duplicate key, and the rules of #? and #?@.

The errors are the compiler's: a file with one would not load. The checks were calibrated against clj-kondo on the same 1,777 files, and on that code -- which compiles -- the error checks report next to nothing.

Calibration

The name checks only run where the server can see the whole picture:

  • On Clojure code: a .clj or .bb file, or the :clj and :default branches of a .cljc one. Not on ClojureScript (cljs.core and js/ interop are not in its tables) and not in an .edn file, which is data.
  • Macros are not expanded. clojure.core's are known form by form (what let, fn, for, defrecord, case, ->, doto... bind and evaluate). A call it cannot identify -- a library's macro -- turns the name checks off inside it, and every symbol written in a vector among its arguments counts as bound there (go-loop [x 1], are [x y]), the common shape of a macro that binds names.
  • A file that =:use=s or =:refer :all=s a namespace the server does not know, or that has more than five names it cannot place, depends on a context it cannot see (code =load=ed into another namespace, a macro library) and gets no unresolved-* at all.

What else it does

  • Hover shows a var's arglists, docstring, namespace and the version it was added in (and its deprecation); a special form's; a local's binding.
  • Completion offers the locals in scope first, then the file's own vars, referred names, clojure.core and the special forms; after alias/, that namespace's public vars (core's from the table, the project's from the index); after :, the keywords the file uses; inside (:require [, namespace names.
  • Signature help shows the arglists of the function being called, with the arity that fits and the argument being typed highlighted.
  • Go to definition follows a local to its binding, a var to its def -- in this file or another one of the project. References, highlights and rename cover a local (in its scope) or one of the file's own vars; a core var or a keyword cannot be renamed.
  • The outline lists the namespace, then each definition, with a protocol's methods and a record's fields under it.
  • Folding covers every multi-line form and runs of comment lines.
  • Formatting is mep's Clojure formatter, the one gf runs: cljfmt's layout. See Formatting. A file that does not read is left alone.

Linting from the command line

sh Copy
mep-clojure-lsp --lint src/**/*.clj
cat core.clj | mep-clojure-lsp --lint -

prints every diagnostic as

src/app/core.clj:12:9: warning: unused binding tmp [unused-binding]

-- 1-based line and column, then the severity (error, warning, info, hint), the message and the code. It exits 1 if anything printed is an error or a warning, 2 if a file could not be read, and 0 otherwise. Each file is read on its own, without the project index. With no arguments, mep-clojure-lsp is the language server on stdio.

Using clojure-lsp instead

lua Copy
mep.lsp_servers.clojure_lsp.filetypes = {'clj', 'cljs', 'cljc', 'cljd', 'edn', 'bb'}
mep.lsp_servers.clojure_ls.filetypes = {}

clojure-lsp (with clj-kondo inside it) reads the project's classpath and so knows its libraries; mep's server needs no JVM, no deps.edn and no network.
