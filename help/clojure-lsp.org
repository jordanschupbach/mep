* What it is

Clojure files get a language server of their own, =mep-clojure-lsp=, built
and shipped with mep. Open a =.clj=, =.cljs=, =.cljc=, =.cljd=, =.edn= or
=.bb= file and it attaches by itself -- nothing to install, *no JVM is
started and nothing is evaluated*. It reads the file with mep's own
Clojure reader and knows =clojure.core= and the namespaces that ship with
Clojure (=clojure.string=, =clojure.set=, =clojure.walk=, ...) from a table
generated from Clojure itself: every var's arglists, docstring, the
version it was added in, and whether it is deprecated or private.

On start it indexes the workspace's =.clj=, =.cljc=, =.cljs= and =.bb=
files -- each one's namespace and vars, with their arglists and
docstrings -- so definition, hover, completion after =alias/= and argument
counts reach across files. An open file is re-indexed as you type.

The same binary is a command-line linter; see /Linting from the command line/ below.

* The same read errors as Clojure

Its reader errors are the ones the JVM's reader raises, worded the same
way, at the same place: the reader is checked against Clojure's own
(=clojure.core/read= with reader conditionals allowed) on 4,755 files --
the 1,777 files of mep's Clojure corpus (Clojure's and ClojureScript's own
source, clj-kondo, clojure-lsp, babashka, rewrite-clj...) and damaged
copies of them -- and agrees on 4,754. That covers unmatched and unclosed
delimiters, bad numbers and tokens (=08=, =1.2.3=, =\abc=), string and
character escapes, regexes, metadata, nested =#()=, =##Inf=-style values,
namespaced maps, a map with an odd number of forms or a duplicate key, and
the rules of =#?= and =#?@=.

* What it reports

| Code                      | Severity | What it means                                                     |
|---------------------------+----------+-------------------------------------------------------------------|
| (reader codes)            | error    | what the JVM's reader says, in its words: =eof=, =unmatched-delimiter=, =invalid-number=, =invalid-token=, =string-escape=, =odd-map=, =duplicate-key=, =read-cond=, ... |
| =reader-conditional=      | error    | a =#?= in a =.clj= file, which =load= reads without them          |
| =def-shape=, =defn-shape=, =fn-shape= | error | a =def=/=defn=/=fn= the compiler rejects: no name, no parameter vector |
| =binding-shape=           | error    | =let=, =loop=, =for=, =doseq=... without a vector, or with an odd one |
| =if-shape=                | error    | =if= with too few or too many forms                               |
| =duplicate-case-test=     | error    | the same constant twice in a =case=                               |
| =unresolved-symbol=       | error    | a name nothing defines, binds or refers (calibrated, below)       |
| =unresolved-namespace=    | error    | =alias/x= with no such alias                                      |
| =unresolved-var=          | error    | =str/no-such-fn= in a namespace the server knows                  |
| =use-before-definition=   | error    | a var used above its =def= in the same file                       |
| =invalid-arity=           | error    | a call with a number of arguments none of the arglists takes      |
| =private-var=             | warning  | =ns/x= naming a var its namespace keeps private                   |
| =namespace-name-mismatch= | warning  | =(ns a.b-c)= in a file that is not =a/b_c.clj=                    |
| =inline-def=              | warning  | a =def= inside a function body                                    |
| =unused-binding=          | warning  | a =let=/=fn= local never read (=_x= is how to say "on purpose")   |
| =unused-private-var=      | warning  | a =defn-= or =^:private= var the file never uses                  |
| =unused-namespace=        | warning  | a =:require= whose alias and refers are never used                |
| =unused-referred-var=     | warning  | a =:refer= name never used                                        |
| =duplicate-require=       | warning  | the same namespace required twice                                 |
| =redefined-var=           | warning  | the same var defined twice in the file                            |
| =misplaced-docstring=     | warning  | =(defn f [x] "doc" ...)=: the string is the body, not the doc     |
| =deprecated-var=          | warning  | a var Clojure marks deprecated (=replicate=, =agent-errors=...)   |
| =redundant-do=            | hint     | =(do x)=: a =do= wrapping a single form                           |
| =not-empty=               | hint     | =(not (empty? x))= -- =(seq x)= says it                           |

The errors are the compiler's: a file with one would not load. The checks
were calibrated against =clj-kondo= on the same 1,777 files, and on that
code -- which compiles -- the error checks report next to nothing.

** Calibration

The name checks only run where the server can see the whole picture:

- On Clojure code: a =.clj= or =.bb= file, or the =:clj= and =:default=
  branches of a =.cljc= one. Not on ClojureScript (=cljs.core= and =js/=
  interop are not in its tables) and not in an =.edn= file, which is data.
- Macros are not expanded. =clojure.core='s are known form by form (what
  =let=, =fn=, =for=, =defrecord=, =case=, =->=, =doto=... bind and
  evaluate). A call it cannot identify -- a library's macro -- turns the
  name checks off inside it, and every symbol written in a vector among its
  arguments counts as bound there (=go-loop [x 1]=, =are [x y]=), the
  common shape of a macro that binds names.
- A file that =:use=s or =:refer :all=s a namespace the server does not
  know, or that has more than five names it cannot place, depends on a
  context it cannot see (code =load=ed into another namespace, a macro
  library) and gets no =unresolved-*= at all.

* What else it does

- *Hover* shows a var's arglists, docstring, namespace and the version it
  was added in (and its deprecation); a special form's; a local's
  binding.
- *Completion* offers the locals in scope first, then the file's own vars,
  referred names, =clojure.core= and the special forms; after =alias/=,
  that namespace's public vars (core's from the table, the project's from
  the index); after =:=, the keywords the file uses; inside
  =(:require [=, namespace names.
- *Signature help* shows the arglists of the function being called, with
  the arity that fits and the argument being typed highlighted.
- *Go to definition* follows a local to its binding, a var to its =def= --
  in this file or another one of the project. *References*, *highlights* and *rename* cover a local (in its
  scope) or one of the file's own vars; a core var or a keyword cannot be
  renamed.
- The *outline* lists the namespace, then each definition, with a
  protocol's methods and a record's fields under it.
- *Folding* covers every multi-line form and runs of comment lines.
- *Formatting* is mep's Clojure formatter, the one =gf= runs: =cljfmt='s
  layout. See [[file:formatting.html][Formatting]]. A file that does not
  read is left alone.

* Linting from the command line

#+begin_src sh
mep-clojure-lsp --lint src/**/*.clj
cat core.clj | mep-clojure-lsp --lint -
#+end_src

prints every diagnostic as

#+begin_example
src/app/core.clj:12:9: warning: unused binding tmp [unused-binding]
#+end_example

-- 1-based line and column, then the severity (=error=, =warning=,
=info=, =hint=), the message and the code. It exits 1 if anything printed
is an error or a warning, 2 if a file could not be read, and 0 otherwise.
Each file is read on its own, without the project index. With no
arguments, =mep-clojure-lsp= is the language server on stdio.

* Using clojure-lsp instead

#+begin_src lua
mep.lsp_servers.clojure_lsp.filetypes = {'clj', 'cljs', 'cljc', 'cljd', 'edn', 'bb'}
mep.lsp_servers.clojure_ls.filetypes = {}
#+end_src

=clojure-lsp= (with =clj-kondo= inside it) reads the project's classpath
and so knows its libraries; mep's server needs no JVM, no =deps.edn= and no
network.
