The command line

Using it

: opens the command line at the bottom of the window. Type a command and press Enter; Esc cancels.

KeyDoes
Up / Downwalk through command history
Tabcomplete the command name, or a file path
Ctrl-R {reg}insert a register's text
Ctrl-Shift-Vpaste the clipboard
Esccancel

Completion knows which commands take a path and offers directory entries for those, and command names everywhere else.

The / and ? search prompts behave the same way, with their own history. Text inserted at either prompt is kept to a single printable line.

Files and windows

CommandDoes
:e {file}open a file -- a path that does not exist yet starts a new buffer
:w [file]write, optionally to a different path
:wawrite every modified buffer that has a name
:q :q!close the pane, discarding changes with !
:qa :qa!quit everything
:wq :xwrite, then close
:wqa :xawrite everything, then quit
:split :vsplitsplit the current pane
:closeclose the current pane
:tabnew :tabdeletemanage tabs
:bnext :bprevious :bdeletecycle or close buffers

:qa refuses if any buffer anywhere has unsaved changes, so nothing hidden in another workspace is lost silently.

Jumping and running

CommandDoes
:42go to line 42
:normal {keys}run keys as literal Normal-mode input
:lua {code}run Lua
:source {file}run a Lua file
:terminalopen a shell in a split below

:normal is the natural partner for :g: :g/TODO/normal A -- done appends to every matching line. :norm is the short form.

Options

:set changes an option for the session.

OptionDefaultDoes
number / nuonline numbers in the gutter
relativenumber / rnuondistances instead of numbers
cursorline / culhighlight the cursor's line
wraponsoft-wrap long lines
ignorecaseoffcase-insensitive search and :s
wrapscanonsearch wraps around the buffer
textwidth=N / tw=N80the column gq wraps to

Prefix a boolean option with no to turn it off: :set nowrap, :set nonumber norelativenumber.

For anything persistent, set it in ~/.config/mep/init.lua instead.

Finding a command

Almost every feature has a :Mep... command, and there are over two hundred of them. Three ways to find the one you want:

  • Tab at the command line completes command names.
  • <Space> shows the which-key popup of leader bindings, which is how most commands are reached in practice.
  • <leader>hk lists every key binding currently in effect.
