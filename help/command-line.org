* Using it

=:= opens the command line at the bottom of the window. Type a command and
press Enter; =Esc= cancels.

| Key            | Does                                        |
|----------------+---------------------------------------------|
| Up / Down      | walk through command history                |
| =Tab=          | complete the command name, or a file path   |
| =Ctrl-R {reg}= | insert a register's text                    |
| =Ctrl-Shift-V= | paste the clipboard                         |
| =Esc=          | cancel                                      |

Completion knows which commands take a path and offers directory entries
for those, and command names everywhere else.

The =/= and =?= search prompts behave the same way, with their own history.
Text inserted at either prompt is kept to a single printable line.

* Files and windows

| Command            | Does                                          |
|--------------------+-----------------------------------------------|
| =:e {file}=        | open a file -- a path that does not exist yet starts a new buffer |
| =:w [file]=        | write, optionally to a different path         |
| =:wa=              | write every modified buffer that has a name   |
| =:q= =:q!=         | close the pane, discarding changes with =!=   |
| =:qa= =:qa!=       | quit everything                               |
| =:wq= =:x=         | write, then close                             |
| =:wqa= =:xa=       | write everything, then quit                   |
| =:split= =:vsplit= | split the current pane                        |
| =:close=           | close the current pane                        |
| =:tabnew= =:tabdelete= | manage tabs                               |
| =:bnext= =:bprevious= =:bdelete= | cycle or close buffers          |

=:qa= refuses if *any* buffer anywhere has unsaved changes, so nothing
hidden in another workspace is lost silently.

* Jumping and running

| Command          | Does                                                  |
|------------------+-------------------------------------------------------|
| =:42=            | go to line 42                                         |
| =:normal {keys}= | run =keys= as literal Normal-mode input               |
| =:lua {code}=    | run Lua                                               |
| =:source {file}= | run a Lua file                                        |
| =:terminal=      | open a shell in a split below                         |

=:normal= is the natural partner for =:g=: =:g/TODO/normal A -- done= appends
to every matching line. =:norm= is the short form.

* Options

=:set= changes an option for the session.

| Option                       | Default | Does                            |
|------------------------------+---------+---------------------------------|
| =number= / =nu=              | on      | line numbers in the gutter      |
| =relativenumber= / =rnu=     | on      | distances instead of numbers    |
| =cursorline= / =cul=         |         | highlight the cursor's line     |
| =wrap=                       | on      | soft-wrap long lines            |
| =ignorecase=                 | off     | case-insensitive search and =:s= |
| =wrapscan=                   | on      | search wraps around the buffer  |
| =textwidth=N= / =tw=N=       | 80      | the column =gq= wraps to        |
| =pasteindent= / =pi=         | on      | re-indent a multi-line paste    |
| =pyindent=                   | on      | re-indent Python on save        |
| =smarttab= / =sta=           | on      | Backspace eats a whole soft tab |
| =caretdelay=MS=              | system  | hold before the caret repeats   |
| =caretrate=N=                | system  | caret steps per second held     |
| =maxfps=N=                   | 0       | cap on frames drawn per second  |

Prefix a boolean option with =no= to turn it off: =:set nowrap=,
=:set nonumber norelativenumber=.

** Caret repeat speed

Holding =h=, =j=, =k=, =l= or an arrow key repeats the motion on mep's own
timer, not on the OS's key-repeat events. By default it copies whatever
repeat delay and rate the system is configured with, so the caret moves at
the speed everything else on the machine does.

=:set caretdelay= (milliseconds before repeating starts) and =:set caretrate=
(steps per second once it does) override that. Neither is clamped to what the
OS itself would repeat at -- the point being platforms that cap their own
repeat rate well below what a fast typist wants, macOS in particular, where
the Key Repeat slider stops around 30/s:

#+begin_src
:set caretrate=120
:set caretdelay=140
#+end_src

=0= restores "follow the system" for either one. A rate higher than the
display's refresh rate has no further effect, since the caret can move at
most one step per frame drawn.

** Frame rate

=:set maxfps=N= caps how many frames a second mep draws. =0=, the default,
means no cap: vsync paces the loop, so mep draws at the display's refresh
rate.

Worth setting on a laptop. mep redraws every frame whether or not anything
changed, so an idle editor's CPU cost is almost entirely redrawing, and a
cap gives back CPU in proportion to the frames it skips -- measured on a
165Hz screen, as a percentage of one core while idle:

| =maxfps= | frames drawn | idle CPU |
|----------+--------------+----------|
| =0=      | 163/s        | 32%      |
| =120=    | 119/s        | 24%      |
| =60=     | 60/s         | 12%      |
| =30=     | 30/s         | 6%       |

The cost is smoothness: scrolling and caret movement on a high-refresh
screen are visibly less fluid capped than not. Nothing tears either way.

One interaction to know: the caret moves at most one step per frame, so a
=maxfps= below your caret rate becomes the caret's ceiling -- =:set
maxfps=30= turns a 50/s caret into a 30/s one.

For anything persistent, set it in =~/.config/mep/init.lua= instead.

* Finding a command

Almost every feature has a =:Mep...= command, and there are over two hundred
of them. Three ways to find the one you want:

- =Tab= at the command line completes command names.
- =<Space>= shows the which-key popup of leader bindings, which is how most
  commands are reached in practice.
- =<leader>hk= lists every key binding currently in effect.
