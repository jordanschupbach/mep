GitHub Copilot

Inline completions, on by default

As you type, a suggestion appears dimmed in place -- as if it were already written -- and Tab accepts it.

KeyWhile a suggestion is showing
Tabaccept the whole suggestion
Alt-Rightaccept one more word
Alt-Ctrl-Rightaccept one more line
Ctrl-]dismiss it

Typing the characters the suggestion was going to insert keeps it up: it shrinks from the front, so you can type along with it and Tab out whenever you like.

Tab belongs to the completion popup whenever that popup is open, so the two never fight over the key.

Signing in

mep drives GitHub's own copilot-language-server. Install it with

npm i -g @github/copilot-language-server

or let mep fall back to npx, or point mep.copilot_server_cmd at your own build. Then:

:CopilotLogin

which shows a device code, copies it to your clipboard, and offers to open github.com/login/device in your real browser.

mep never sees the resulting token. The language server runs the device flow itself and keeps credentials in ~/.config/github-copilot -- the same directory the VS Code, Neovim and JetBrains clients share, so signing in once covers all of them. Nothing about the token crosses mep's socket in either direction, and nothing is written into mep's own config.

Commands

CommandDoes
:Copilotturn it on, starting the server
:Copilot offturn it off
:Copilot toggleflip it
:Copilot restartrestart the server
:Copilot suggestask right now, ignoring the idle delay
:CopilotStatusserver, sign-in, account, and whether this buffer is being sent
:CopilotPanelseveral alternatives at once, in the picker
:CopilotLogin / :CopilotLogoutsign in / out

What gets sent, and turning it off

A completion request ships the surrounding buffer text to GitHub. Files whose whole point is to hold a secret are never sent at all -- .env, *.pem, *.key, id_rsa, .netrc, secrets.yaml and friends.

lua Copy
mep.copilot_exclude_patterns   -- the list; extend it
mep.copilot_filetypes['md'] = false   -- off for one filetype
mep.copilot_enabled = false           -- off entirely, before any server starts

Setting copilot_enabled = false in init.lua means no server is ever started, rather than one started and ignored.
