* Inline completions, on by default

As you type, a suggestion appears dimmed in place -- as if it were already
written -- and =Tab= accepts it.

| Key              | While a suggestion is showing |
|------------------+-------------------------------|
| =Tab=            | accept the whole suggestion   |
| =Alt-Right=      | accept one more word          |
| =Alt-Ctrl-Right= | accept one more line          |
| =Ctrl-]=         | dismiss it                    |

Typing the characters the suggestion was going to insert keeps it up: it
shrinks from the front, so you can type along with it and =Tab= out whenever
you like.

=Tab= belongs to the completion popup whenever that popup is open, so the
two never fight over the key.

* Signing in

mep drives GitHub's own =copilot-language-server=. Install it with

#+begin_example
npm i -g @github/copilot-language-server
#+end_example

or let mep fall back to =npx=, or point =mep.copilot_server_cmd= at your own
build. Then:

#+begin_example
:CopilotLogin
#+end_example

which shows a device code, copies it to your clipboard, and offers to open
=github.com/login/device= in your real browser.

*mep never sees the resulting token.* The language server runs the device
flow itself and keeps credentials in =~/.config/github-copilot= -- the same
directory the VS Code, Neovim and JetBrains clients share, so signing in
once covers all of them. Nothing about the token crosses mep's socket in
either direction, and nothing is written into mep's own config.

* Commands

| Command             | Does                                          |
|---------------------+-----------------------------------------------|
| =:Copilot=          | turn it on, starting the server               |
| =:Copilot off=      | turn it off                                   |
| =:Copilot toggle=   | flip it                                       |
| =:Copilot restart=  | restart the server                            |
| =:Copilot suggest=  | ask right now, ignoring the idle delay        |
| =:CopilotStatus=    | server, sign-in, account, and whether this buffer is being sent |
| =:CopilotPanel=     | several alternatives at once, in the picker   |
| =:CopilotLogin= / =:CopilotLogout= | sign in / out                  |

* What gets sent, and turning it off

A completion request ships the surrounding buffer text to GitHub. Files
whose whole point is to hold a secret are never sent at all -- =.env=,
=*.pem=, =*.key=, =id_rsa=, =.netrc=, =secrets.yaml= and friends.

#+begin_src lua
mep.copilot_exclude_patterns   -- the list; extend it
mep.copilot_filetypes['md'] = false   -- off for one filetype
mep.copilot_enabled = false           -- off entirely, before any server starts
#+end_src

Setting =copilot_enabled = false= in =init.lua= means no server is ever
started, rather than one started and ignored.
