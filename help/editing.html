Editing basics

Buffers and panes

mep uses modal editing. Files are buffers, and panes are views onto those buffers. Use :e path to open a file and :w to save it.

Help pages

Help pages are rendered HTML documents. Their Org sources use headings, lists, and links, then export to the HTML pages shown here.

For the conventions used by this help workspace, see Writing help pages.
