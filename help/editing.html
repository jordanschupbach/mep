Editing basics

The model

Three ideas carry almost all of mep's editing.

Modes. What a key does depends on the mode. In Normal mode letters are commands; in Insert mode they are text. See Modes.

Operator plus motion. A command that changes text is usually an operator (d delete, c change, y yank) followed by something describing the range: a motion (dw, delete to the next word) or a text object (diw, delete the word the cursor is in). Learn the operators once and every motion you already know composes with them. See Operators and text objects.

Counts. Almost anything takes a leading number, and it means "do this that many times": 3j, d2w, 5dd, 10G.

Buffers and panes

A buffer is an open file's contents in memory. A pane is a view onto a buffer. The two are separate, which is why several panes can show the same buffer -- including the same buffer twice, with independent cursors but one shared undo history.

:e path opens a file into a buffer, :w writes it back. :split and :vsplit divide the current pane; Ctrl-W followed by h, j, k or l moves focus between them.

Buffers belong to the workspace they were opened in, which is why :ls and the buffer picker show that workspace's buffers rather than everything open in the process.
