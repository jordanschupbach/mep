The file tree

Opening it

<leader>ff toggles the file tree (:MepFileTree, or the Files button in the tab bar). It opens on the left, rooted at the active workspace, with a Nerd Font icon per file type.

It is a pane rather than a sidebar, so the usual pane keys work on it.

Keys

KeyDoes
Enteropen the file, or expand/collapse the directory
aadd a file -- end the name with / for a directory
rrename
ddelete
ccopy
Ycopy the path to the clipboard
eedit the directory as text (oil-style)
oopen with the operating system
-move the root up one directory
Cmake the directory under the cursor the root
Rrefresh
Hshow or hide hidden files
Iopen the directory in the image viewer
qclose the tree

Navigation keys:

KeyDoes
j kmove down / up
gg Gfirst / last row
/search within the tree
?show or hide the key list

The bottom row always hints ?: help. Pressing ? swaps the tree for its key list; Esc, ? or q go back.

Editing a directory as text

e turns the directory into a text buffer, one entry per line (:MepOil). Rename by editing a line, delete by deleting a line, create by adding one. Write the buffer and the changes are applied to disk.

This is much the fastest way to make several changes at once.

Dragging onto a pane

A file row can be dragged onto any pane. A drop-zone pinwheel appears under the pointer: the centre opens the file in that pane, an edge splits the pane that way and opens it in the new half.

Related commands

Command / keyDoes
<leader>fhtoggle hidden files
<leader>frrefresh the tree
<leader>foopen a file through the native dialog
<leader>ffalso the "find files" picker, when no tree is focused

Stacking with other panels

Sidebars docked on the same edge share one column, split vertically. Opening Git Status next to the tree stacks it below rather than beside. Drag the divider between them, or use mod1+Shift+j/k from inside one, to change the split; mod1+j/k steps focus between them.
