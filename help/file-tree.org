* Opening it

=<leader>ff= toggles the file tree (=:MepFileTree=, or the Files button in
the tab bar). It opens on the left, rooted at the active workspace, with a
Nerd Font icon per file type.

It is a pane rather than a sidebar, so the usual pane keys work on it.

* Keys

| Key       | Does                                            |
|-----------+-------------------------------------------------|
| =Enter=   | open the file, or expand/collapse the directory |
| =a=       | add a file -- end the name with =/= for a directory |
| =r=       | rename                                          |
| =d=       | delete                                          |
| =c=       | copy, to a name you type                        |
| =y=       | yank the entry                                  |
| =p=       | paste a copy of it into the directory under the cursor (or the file's own) -- "name copy" if the name is taken |
| =Y=       | copy the path to the clipboard                  |
| =o=       | open with the operating system                  |
| =-=       | move the root up one directory                  |
| =C=       | make the directory under the cursor the root    |
| =R=       | refresh                                         |
| =H=       | show or hide hidden and git-ignored files       |
| =I=       | open the directory in the image viewer          |
| =P=       | show or hide the preview beside the tree        |
| =q=       | close the tree                                  |

Navigation keys:

| Key        | Does                       |
|------------+----------------------------|
| =j= =k=    | move down / up             |
| =gg= =G=   | first / last row           |
| =/=        | search within the tree     |
| =?=        | show or hide the key list  |

The bottom row always hints =?: help=. Pressing =?= swaps the tree for its
key list; =Esc=, =?= or =q= go back.

* Keeping up with the filesystem

While the tree is on screen it re-reads the directories it is showing about
once a second, so a file added or removed behind its back -- =:w= to a new
path, a terminal, a =git checkout=, an agent, another editor -- appears or
disappears on its own. Only expanded directories are walked, and the row
under the cursor stays under the cursor when rows above it shift.

Files and directories git ignores are left out of the tree, and that list is
re-read shortly after a change, so build output does not drift into view.
Showing hidden files (=H= or =<leader>fh=) brings them back along with the
dotfiles, dimmed so they still read as ignored; everything inside an ignored
directory is dimmed the same way.

=R= (or =<leader>fr=) still refreshes immediately. Setting
=mep.tree_auto_refresh = false= in your config turns the polling off, leaving
the tree to refresh only on those keys and on its own =a= / =r= / =d= / =c=
edits.

* Previewing files

While the tree has focus, a small box beside it previews the row under the
cursor: the first lines of a text file (highlighted by its file type), a
directory's entries, an image (PNG, JPEG, GIF, BMP, SVG ...), or the first page
of a PDF with its page count. Binary files show their size. The box stays level
with the cursor row, on whichever side of the tree has more room, and goes away
as soon as you move into another pane.

The box appears once the cursor has rested on a row for two seconds, and
the old one goes away as soon as you move; set =mep.tree_preview_delay= (in
seconds, =0= for straight away) in your config to change the wait.

The preview is on by default. =P= in the tree, =:MepFileTreePreview= or
=<leader>fp= turns it off and on again; =mep.tree_preview = false= in your
config starts with it off.

* Dragging onto a pane

A file row can be dragged onto any pane. A drop-zone pinwheel appears under
the pointer: the centre opens the file in that pane, an edge splits the pane
that way and opens it in the new half.

* Related commands

| Command / key   | Does                                        |
|-----------------+---------------------------------------------|
| =<leader>fh=    | toggle hidden and git-ignored files         |
| =<leader>fp=    | toggle the file preview (=:MepFileTreePreview=) |
| =<leader>fr=    | refresh the tree                            |
| =<leader>fo=    | open a file through the native dialog        |
| =<leader>ff=    | also the "find files" picker, when no tree is focused |

* Stacking with other panels

Sidebars docked on the same edge share one column, split vertically. Opening
Git Status next to the tree stacks it below rather than beside. Drag the
divider between them, or use =mod1+Shift+j/k= from inside one, to change the
split; =mod1+j/k= steps focus between them.
