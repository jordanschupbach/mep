* What each filetype gets

| Filetype     | Syntax        | Language server              | Formatter      | Runs with |
|--------------+---------------+------------------------------+----------------+-----------|
| C            | Treesitter    | =mep-c-lsp=, =clangd=        | =clang-format= | =cc=      |
| C++          | Treesitter    | =clangd=                     | =clang-format= | =c++=     |
| Python       | Treesitter    | =mep-python-lsp=, =pyright=  | built in       | =python3= |
| Lua          | Treesitter    | =lua-language-server=        | LSP            |           |
| R            | Treesitter    | R's =languageserver=         | built in       | =Rscript= |
| JavaScript   | Treesitter    | =typescript-language-server= | LSP            |           |
| Markdown     | Treesitter    | =marksman=                   | LSP            |           |
| Org          | Treesitter    |                              |                |           |
| Go           | grammar via =just fetch-grammars= | =gopls=  | LSP            |           |
| Rust         | grammar via =just fetch-grammars= | =rust-analyzer= | LSP     |           |
| everything else | per-line lexer | see [[file:lsp.html][Language servers]]    | LSP if attached |          |

Eight grammars are compiled in: =c=, =cpp=, =javascript=, =lua=,
=markdown=, =org=, =python=, =r=. About fifty more are one
=just fetch-grammars= away -- see [[file:syntax.html][Syntax highlighting]].
