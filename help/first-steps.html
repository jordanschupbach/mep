Your first ten minutes

Modes

mep starts in Normal mode, where the letter keys are commands rather than text. This is the single thing to understand first: in Normal mode, pressing d does not type a "d", it starts a delete.

The current mode is shown at the left of the status line along the bottom.

Moving

Use h, j, k and l to move left, down, up and right. They are where your fingers already are, which is the whole argument for them.

KeyMoves to
w / bstart of the next / previous word
0 / $start / end of the line
^first non-blank character of the line
gg / Gfirst / last line of the file
5jdown five lines -- any motion takes a count
:42line 42

To get somewhere visible on screen fast, press s and start typing what you are aiming at. Every match across every visible pane gets a one-key label; press that key to jump. Press Esc to give up.

Editing

Press i to start typing at the cursor, or a to start just after it. o opens a new line below and starts typing there. Esc gets you back to Normal mode.

In Normal mode, an operator combines with a motion:

KeysEffect
dwdelete to the start of the next word
dddelete the whole line
3dddelete three lines
cwchange a word (delete it, then Insert)
yyyank (copy) a line
pput (paste) what you last yanked or deleted
xdelete the character under the cursor
uundo; Ctrl-r redo

Yanking and deleting put the text on the system clipboard, so p pastes what you copied in any other application too, and vice versa.

Saving and quitting

Everything here starts with :, which opens the command line at the bottom.

CommandEffect
:wwrite the current buffer to its file
:e pathopen path -- a path that does not exist yet starts a new file
:qclose the current pane, quitting once it is the last
:q!close it, discarding unsaved changes
:wqwrite, then close
:qaquit everything, refusing if anything is unsaved

If :q refuses, something is unsaved. :wa writes every modified buffer.

When you forget a key

Press <Space> and wait. The which-key popup lists every binding available under the leader key, grouped by what it does -- f for files, g for git, o for org, and so on. Keep pressing keys to walk into a group; press Esc to back out.
