The git gutter

Marks beside changed lines

The gutter is on by default. Every line you have changed since the base revision gets a mark in the sign column:

MarkMeans
a green barthis line was added
a yellow barthis line was changed
a red stripelines were deleted next to this one

A deletion that ran off the top of the file marks the top edge of line 1. A changed line that also dropped lines gets both a bar and a stripe.

The marks are drawn as rectangles rather than glyphs, because none of the embedded fonts cover the box-drawing block Neovim's defaults use.

It diffs what you are typing

The gutter diffs the buffer's live, unsaved text -- not what is on disk. Marks appear as you type, on a debounce, and update when you switch buffers or act from the git panel.

A file outside a repository gets no marks. A file inside one but not in the base -- new or untracked -- reads as entirely added.

The base is HEAD, and that is deliberate

By default the gutter compares against HEAD, so *staging a change does not make its marks disappear*.

This differs from gitsigns.nvim and vim-gitgutter, which both compare against the index and so go blank the moment you git add. Both staging a hunk (<leader>ga) and the git panel's S are one keystroke, and after either one an index-based gutter shows nothing on a file full of changes -- which is not what most people want to see.

:MepGitGutter base index     " the stage-aware view, if you prefer it
:MepGitGutter base HEAD~1    " or any other revision
:MepGitGutter base           " report the current base

Any revision works: a branch name, HEAD~3, a SHA.

Turning it on and off

CommandDoes
:MepGitGutterrecompute now
:MepGitGutter onenable
:MepGitGutter offdisable
:MepGitGutter toggleflip it, reporting which way it went
<leader>gdthe same toggle
lua Copy
-- vim-gitgutter's whole-line tint, on top of the sign-column marks
mep.git_gutter_line_hl = true

For a statusline

lua Copy
mep.git_gutter_summary()   --> "+12 ~3 -1"

Returns the current buffer's added, changed and deleted counts, ready to drop into a custom status line.
