Five views, one panel

Tab and Shift-Tab move between views, as do the keys 1 to 5 and a click on a view's name.

KeyViewShows
1Statusstaged, changed and untracked files
2Loggit log, the latest 300 commits
3Graphgit log --graph --all, the latest 500
4Brancheslocal and remote, newest commit first
5Stashgit stash list

Every view's head section says how far the branch is ahead of and behind its upstream, or that it has none -- so unpushed commits stay in sight whichever view you are in.

mod1+m pops the panel out with a preview column beside the list.

Keys that work everywhere

KeyDoes
ccommit -- the message opens in a float
Camend the last commit
P ppush

Every action reports its result as a toast and refreshes the view.

Status

The preview is git diff --cached or git diff for the row, and the file itself for an untracked one.

KeyDoes
Enteropen the file
sstage this row
uunstage this row
Sstage everything
Uunstage everything
ddiscard changes, or delete an untracked file

d asks first. It is the one destructive key in the panel.

Log and Graph

The preview is git show for the commit under the cursor.

KeyDoes
Entershow the commit, popped out
ycopy the commit hash

Graph draws every branch's history as coloured lanes with the refs on their commits, which is the view to reach for when working out how two branches relate.

Branches

The preview is that branch's git log --oneline. Rows show ahead/behind counts and the upstream.

KeyDoes
Enter ocheck out (a remote one as a tracking branch)
nnew branch from HEAD
x Ddelete -- a remote one via git push --delete
mmerge it into the current branch
rrebase the current branch onto it

Both delete forms confirm first.

Stash

The preview is git stash show -p.

KeyDoes
nstash the working tree, untracked included
Enter aapply
opop
xdrop, after a confirm

n offers a message.

Committing

c opens the repository's own COMMIT_EDITMSG in a floating editable pane, with the usual # status comment block below the message.

KeyDoes
ZZ in Normal modecommit
mod1+d (Alt-d) or :bdabort and discard the message
:q, or a click awaythe same abort

It is a real pane over a real buffer, so every editing mode, motion and operator works while you write the message. Escape here does nothing but leave Insert mode: a half-written commit message is the last thing that should be one stray keystroke away from gone, so aborting one is always something you asked for by name.
