Viewing images

The viewer

.png, .jpg, .bmp and .gif open in a pane.

KeyDoes
+ -zoom in / out
=fit to the pane
dragpan
Ctrl+scrollzoom
eopen the image editor

Transparency is drawn over a checkerboard, and scaling is nearest-neighbour so pixels stay crisp rather than turning to mush when you zoom in.

A directory of images

The file tree's I key opens a directory in the viewer, so you can step through a folder of images rather than opening them one at a time.

From Lua

lua Copy
mep.image_size(buf)        --> width, height
mep.is_image_path(path)    --> is this an image?
mep.image_set_theme(buf, on)

Theming

Images are re-tinted to the active theme by default, like other rendered documents. The header shows [theme, Ctrl-R]; press Ctrl-R to see the image's true colours -- which you want whenever the colours matter.
