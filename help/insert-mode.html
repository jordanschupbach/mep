Esc returns to Normal mode.

Replace mode

R enters Replace mode, where each character you type overwrites the one under the cursor instead of pushing it along. Backspace puts back what was overwritten rather than deleting, so you can retreat through a replacement without losing the original text. Esc leaves.

Keys that work while typing

KeyDoes
Ctrl-Wdelete the word before the cursor
Ctrl-Udelete back to the start of the line
Ctrl-R {reg}insert a register's text, as if typed
Ctrl-Shift-Vpaste the system clipboard directly
Tabaccept an inline AI suggestion, or the completion popup's selection

Ctrl-R takes any register name: ="= or + for the clipboard, a for register a, and so on. It also works on the : command line and the / search prompt, where the inserted text is kept to one printable line.

Completion

A completion popup appears as you type, merging buffer words, snippet triggers, filesystem paths and -- when a language server is attached -- its suggestions, into one list with duplicates collapsed.

While the popup is open Tab belongs to it. Inline AI suggestions (the dimmed text that appears ahead of the cursor) also use Tab, but only when the popup is closed, so the two never compete for the key.

Indentation and snippets

A snippet trigger followed by Tab expands it. After expanding, :MepSnippetNext and :MepSnippetPrev move between its tabstops. Jumping between tabstops immediately after expansion is reliable; editing heavily before jumping to a later tabstop can leave it stale, because positions are computed once at expansion time.
