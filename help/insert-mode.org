* Getting in

| Key | Starts typing                             |
|-----+-------------------------------------------|
| =i= | before the cursor                         |
| =a= | after the cursor                          |
| =I= | at the first non-blank of the line        |
| =A= | at the end of the line                    |
| =o= | on a new line below                       |
| =O= | on a new line above                       |
| =c= | after deleting whatever its motion covered |

=Esc= returns to Normal mode.

* Replace mode

=R= enters Replace mode, where each character you type overwrites the one
under the cursor instead of pushing it along. Backspace puts back what was
overwritten rather than deleting, so you can retreat through a replacement
without losing the original text. =Esc= leaves.

* Keys that work while typing

| Key              | Does                                            |
|------------------+-------------------------------------------------|
| =Ctrl-W=         | delete the word before the cursor               |
| =Ctrl-U=         | delete back to the start of the line            |
| =Ctrl-R {reg}=   | insert a register's text, as if typed           |
| =Ctrl-Shift-V=   | paste the system clipboard directly             |
| =Tab=            | accept an inline AI suggestion, or the completion popup's selection |

=Ctrl-R= takes any register name: ="= or =+= for the clipboard, =a= for
register =a=, and so on. It also works on the =:= command line and the =/=
search prompt, where the inserted text is kept to one printable line.

* Completion

A completion popup appears as you type, merging buffer words, snippet
triggers, filesystem paths and -- when a language server is attached --
its suggestions, into one list with duplicates collapsed. =Ctrl-N= /
=Ctrl-P= move through it (=Ctrl-N= also opens it when it is shut),
=Ctrl-Y= accepts, =Ctrl-E= opens or closes it.

In a code buffer, while the popup is open =Tab= belongs to it. Inline AI
suggestions (the dimmed text that appears ahead of the cursor) also use
=Tab=, but only when the popup is closed, so the two never compete for the
key; =Ctrl-L= accepts one too.

Org, LaTeX and Markdown notes keep the popup off =Tab= altogether -- see
[[file:org-notes.html][Note-taking]]. There =Enter= accepts only an entry
you moved onto with =Ctrl-N= / =Ctrl-P=; otherwise it is a newline.

* Snippets

A snippet trigger followed by =Tab= expands it in a code buffer (in a note,
accept it from the popup instead). =Tab= / =Shift-Tab= then move between
its fields, typing replaces a field's placeholder, and =Tab= from the last
field jumps past the end. Outside a snippet, =Tab= indents. See
[[file:snippets.html][Snippets]].
