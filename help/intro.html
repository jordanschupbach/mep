mep Help

Welcome

mep is a modal editor. It opens with an empty buffer and expects you to press i before you can type; everything else follows from that one idea.

It is also, by now, a good deal more than a text editor: it renders and edits Org and Markdown, PDFs, Word documents, spreadsheets, Jupyter notebooks, images, 3D models and web pages, each in an ordinary pane, and it has its own browser, its own Lua scripting layer, and its own agent protocol.

This is the manual. The sidebar on the left groups every page by topic; click a page to read it, or press f to label every link on screen and jump to one by typing its letter.

Finding your way around

The manual runs to a hundred pages, so there are three ways in.

KeyDoes
<leader>hhopen the page for whatever you are looking at
<leader>hfsearch every page title and heading
:help <topic>jump straight to a page by name

<leader>hh is contextual: press it in a notebook and you get the notebook page, in an R file the R mode page, in a 3D scene the modeler page. With nothing in particular open it brings you here.

Inside a page, f labels every visible link so you can follow one by typing its letter.

Answering "how do I..." without leaving the editor

KeyWhat it gives you
<Space>the which-key popup: every leader binding, grouped and named
<leader>hka searchable list of every key binding currently in effect
:the command line, with completion over every command name

Two generated pages list everything mep has: the command index and the key index. Each row says which page documents that command or key.
