#+TITLE: mep Help

* Welcome

This is the starting point for mep's built-in help workspace. Help pages are
rendered HTML documents, generated from Org sources maintained with the
editor's normal Org tooling.

Use the left sidebar or click a page link to move between pages.

* Start here

- [[file:editing.html][Editing basics]] explains the normal editing model.
- [[file:shortcuts.html][Keyboard shortcuts]] lists the initial help bindings.
- [[file:org-notes.html][Org note-taking]] covers math autosnippets, org snippets, highlights, and export previews.
- [[file:writing-help.html][Writing help pages]] describes the document format.

* Navigation

From Normal mode, press =<leader>hh= to return here at any time.  =:MepHelp=
does the same thing.
