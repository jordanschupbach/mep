* Seeing what is bound

=<leader>hk= (=:MepKeymaps=) lists every binding currently in effect,
including your own. It is the authoritative answer when the which-key popup
and your memory disagree.

From Lua: =mep.leader_bindings()= and =mep.mapping_descriptions()=.

* The binding functions

| Function                                 | Binds                          |
|------------------------------------------+--------------------------------|
| =mep.map(mode, key, fn)=                 | one key in Normal or Visual    |
| =mep.map_g(key, fn)=                     | a key after =g=                |
| =mep.map_g_visual(key, fn)=              | the same, in Visual mode       |
| =mep.map_bracket_next(key, fn)=          | =]key=                         |
| =mep.map_bracket_prev(key, fn)=          | =[key=                         |
| =mep.map_mod1(key, fn)=                  | a key under =mod1=             |
| =mep.leader_map(seq, desc, fn, icon?, icon_hl?)= | a leader sequence      |
| =mep.leader_group(prefix, label, icon?, icon_hl?)= | names a leader group  |
| =mep.command(name, fn)=                  | a =:name= ex command           |

#+begin_src lua
mep.map('n', 'Y', function() mep.cmd('normal y$') end)
mep.map_g('b', mep.lsp_references)          -- gb
mep.map_bracket_next('e', my_next_error)    -- ]e
mep.map_mod1('S-h', my_function)            -- mod1+Shift+h
mep.command('Reload', function() mep.cmd('e!') end)
#+end_src

* Most defaults are overridable

Much of what feels built in is an ordinary Lua binding registered at
startup, so redefining it in =init.lua= simply replaces it:

- the =mod1= layer, every key of it;
- =s= for [[file:quick-jump.html][quick jump]];
- =K= for LSP hover, =gd= for definition;
- every =<leader>= sequence.

The core modal machinery -- motions, operators, text objects -- is in C++
and is not remappable.

* Changing the modifiers

#+begin_src lua
mep.set_leader(',')      -- default <Space>
mep.set_mod1('super')    -- 'alt' (default), 'ctrl', 'shift', 'super'/'cmd'/'meta'
#+end_src

* mod1 key spellings

=mep.map_mod1= takes a bare letter for =mod1+letter=, or a prefix:

| Spelling  | Means                |
|-----------+----------------------|
| ="h"=     | =mod1+h=             |
| ="S-h"=   | =mod1+Shift+h=       |
| ="C-h"=   | =mod1+Ctrl+h=        |
| ="Tab"=, ="S-Tab"= | those keys  |
| ="CR"=, ="S-CR"=   | Enter       |

* Leader sequences

One character per key, with Enter spelled =<CR>=:

#+begin_src lua
mep.leader_map('a<CR>', 'AI terminal', mep.ai_terminal_open)
#+end_src

=<Return>= and =<Enter>= are accepted too.
