Language UI modes

An IDE layout, per language

A language UI mode rearranges the tab into a layout built for one language: your source, a live session, and a set of panels showing what that session knows -- the variables that exist, the packages loaded, the plots drawn.

It is the RStudio-style idea, available per language and per tab rather than as a whole separate application.

Key / commandDoes
<leader>lutoggle the mode for this file
<leader>uuthe same

At most one mode is active per tab, so switching languages swaps the layout rather than accumulating panels.

gh, in context

gh ("go help") opens documentation for the symbol under the cursor. What answers depends on where you are:

  • in a language UI mode, its own Help tab -- R's help(), Python's pydoc, man for C and C++;
  • otherwise, the LSP hover popup, the same one K opens.

<leader>hs and :MepGoHelp do the same thing.

Adding your own

lua Copy
mep.language_ui_modes.js = {
  open = function()
    -- build the layout you want
  end,
}

mep.language_ui_modes is keyed by language. mep.language_ui_active tracks the open one, and mep.language_ui_layout is the shared layout helper the built-in modes use, so a new mode can match their shape without rebuilding it.

lua Copy
mep.opt.language_ui_poll_interval = 0.5   -- how often panels refresh
