The keys

Every game opens a Learn pane, and the last row lists its keys.

Typed answers are forgiving

The matcher accepts the term and any of its :ALIASES:, ignores case and punctuation, and forgives a one-letter slip on longer answers. So a right answer with a typo is not marked wrong.

Identify the code

Names are hidden systematically rather than randomly: top-level classes become Thing, functions become solve, :HIDE: identifiers become op1, op2..., and the term's own words become thing. Python keywords and builtins are left alone, so the code still reads as code. The real names come back once you have answered.

Spaced repetition

Every summary offers g, which records the session into org-drill's :DRILL_*: properties -- SM-2, with Good for a right answer and Again for a miss.

With #+LEARN_SRS: yes in the deck, later sessions deal due cards first. :MepOrgDrillReview reads the same properties, so the two share one record of what you know.

Building on it

The pieces are reusable: mep.learn_parse_deck(path), the question generators (mep.learn_mc_questions, learn_tf_questions, learn_cloze_questions, learn_fact_questions, learn_match_rounds and others), mep.learn_anonymize_code(lines, card), mep.learn_answer_matches(typed, accepted), and the mep.learn_games and mep.learn_catalog tables.
