* The modes

| Mode         | Enter with                | Leave with        |
|--------------+---------------------------+-------------------|
| Normal       | =Esc=                     |                   |
| Insert       | =i= =a= =I= =A= =o= =O=   | =Esc=             |
| Replace      | =R=                       | =Esc=             |
| Visual       | =v=                       | =Esc= or =v=      |
| Visual Line  | =V=                       | =Esc= or =V=      |
| Visual Block | =Ctrl-V=                  | =Esc= or =Ctrl-V= |
| Command line | =:= =/= =?=               | =Esc=             |
| Terminal     | focusing a terminal pane  | =Ctrl-\ Ctrl-n=   |

The status line's left edge always names the current mode.

* Normal

The mode mep starts in, and the one to return to when you are not sure what
is happening. Keys are commands: motions move the cursor, operators change
text, =:= opens the command line.

=Esc= from anywhere gets you here. Pressing it in Normal mode is harmless,
and also cancels a half-typed command -- a pending count, a pending operator,
a pending register prefix.

* Insert and Replace

=i= inserts before the cursor, =a= after it; =I= and =A= do the same at the
first non-blank and the end of the line; =o= and =O= open a new line below or
above. =R= enters Replace, where typing overwrites what is already there and
Backspace restores it.

Several keys keep working while you type -- =Ctrl-W= to delete a word,
=Ctrl-R= to insert a register. See [[file:insert-mode.html][Insert and Replace]].

* Visual

Select first, then act. =v= selects by character, =V= by whole lines, and
=Ctrl-V= a rectangular block. Motions and text objects extend the selection,
and an operator applies to it. See [[file:visual-mode.html][Visual modes]].

* Command line

=:= opens the ex command line; =/= and =?= open the search prompt, which
behaves the same way. Up and Down walk through history, exactly as a shell
does. =Esc= cancels.

While a command line is open, =Ctrl-R= followed by a register name inserts
that register's text, and =Ctrl-Shift-V= pastes the clipboard. Both are
limited to one printable line here.

* Terminal

A =:terminal= pane runs a real shell. While its pane is focused, mep is in
Terminal mode and *every* key goes to the shell -- including =Esc=, which is
why leaving needs the two-key =Ctrl-\ Ctrl-n=. After that you are in Normal
mode in a terminal buffer, and the usual navigation keys work again.

=Ctrl-Shift-V= pastes the clipboard into the terminal.

* Pending state

Some keys start something and wait for the rest: a count (=3=), an operator
(=d=), a register prefix (="a=), =g=, =z=, or a =f=/=t= character search. The
status line's right side shows what is pending, so a command that seems to do
nothing is usually one waiting for its next key. =Esc= discards it.
