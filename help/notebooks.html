Jupyter notebooks

A notebook is a text buffer

Open a .ipynb and you get the notebook in the "percent" cell format that Jupytext, VS Code and Spyder use: every cell starts with a # %% marker (# %% [markdown] for markdown cells).

That means all the usual motions, edits, undo and search apply to cell source. It is a text buffer, not a web view.

What the text cannot carry -- outputs, execution counts, ids, metadata -- is kept alongside and written back as real nbformat JSON on :w, with Jupyter's own indentation so diffs stay clean.

What you see

Each cell is drawn as a rounded card, markdown cards tinted apart from code, and the cell under the cursor accented. A code cell shows In [n]: and a clickable Run chip, with its outputs underneath: stdout and stderr, the last expression's value, tracebacks, and inline matplotlib figures.

A toolbar across the top has + Code, + Markdown, Run All, Interrupt, Restart and Clear.

Per-cell kernels

Each code cell picks its own kernel, from the dropdown at its top right (or <leader>jK). Out of the box the list offers Python 3 plus whichever of R, JavaScript (Node), Ruby and Bash are on $PATH.

Python 3 is one persistent process, so state and inline figures carry across cells. The others are stateless "script" kernels: each run is a fresh process fed the cell's code on stdin.

A cell with no explicit choice follows the notebook default, and a new cell inherits the previous cell's kernel -- so a block of cells keeps running on whatever the one above it used. Each choice is written to that cell's metadata.kernel on :w.

In [n]: counts up as one shared sequence across every kernel, and runs execute one at a time in order, so a mixed "run all" still goes top to bottom.

lua Copy
mep.opt.notebook_kernels = {
  {name='python3', display_name='Python 3', language='py', mode='python'},
  {name='ir', display_name='R', language='r', mode='script',
   command={'R', '--slave', '--no-save'}},
  {name='deno', display_name='Deno', language='js', mode='script',
   command={'deno', 'run', '-'}},
}

mode is one of:

ModeMeans
pythonthe built-in persistent kernel; no command
protocolyour own long-lived process speaking mep's JSON-line kernel protocol
scripta fresh process per run, code on stdin

language is the Treesitter filetype the cell body is highlighted with.
