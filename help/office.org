* Opening

A =.docx=, =.odt= or =.rtf= file opens as a laid-out page -- headings,
paragraphs, lists, tables and images -- rather than as XML, RTF control
words or a plain-text dump.

=mep.office_reload()= re-reads the file from disk.

* Editing

The document is editable, and =:w= writes it back in its original format.
A =.docx= or =.odt= keeps every part of the file the editor does not model
(page setup, headers and footers); an =.rtf= is written fresh from what is
on the page -- headings, runs with their look, lists, tables and PNG/JPEG
pictures -- so a header or footnote the file came with does not survive a
save.
=u= undoes an edit and =Ctrl-Y= redoes one (the toolbar has both too).

* Theming

Like other rendered documents, the page is drawn in your theme's colours by
default -- white paper in a dark editor is jarring. The header reads
=[theme, Ctrl-R]=; =Ctrl-R= shows the document as it prints, white paper
and black text, with the runs' own colours either way. =mep.office_theme()=
reads or sets the same switch.

* Producing one

From an Org file, =<leader>oeo= (=:MepOrgExportOdt=) writes an =.odt=
directly -- no external converter involved. See [[file:org-export.html][Exporting]].

* Fonts

mep embeds serif, sans and monospace faces specifically for laying these
documents out, so a page looks like a page rather than like editor text.
