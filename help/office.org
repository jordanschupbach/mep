* Opening

A =.docx= or =.odt= file opens as a laid-out page -- headings, paragraphs,
lists, tables and images -- rather than as XML or as a plain-text dump.

=mep.office_reload()= re-reads the file from disk.

* Editing

The document is editable, and =:w= writes it back in its original format.

* Producing one

From an Org file, =<leader>oeo= (=:MepOrgExportOdt=) writes an =.odt=
directly -- no external converter involved. See [[file:org-export.html][Exporting]].

* Fonts

mep embeds serif, sans and monospace faces specifically for laying these
documents out, so a page looks like a page rather than like editor text.
