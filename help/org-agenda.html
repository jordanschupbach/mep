Agenda

The views

CommandShows
:MepOrgAgendaTodaytoday
:MepOrgAgendaWeekthe coming week
:MepOrgAgendaTodoevery open TODO, whatever its date
:MepOrgAgendaOverdueeverything past its deadline
:MepOrgAgendaSearchsearch across the agenda files

Each collects across all your agenda files, which is the point: the agenda is the view that does not care which file something lives in.

Agenda files

:MepOrgAgendaAddFile adds the current file to the set the agenda scans.

Globs are expanded, so one entry can cover a directory of notes rather than being listed file by file.
