* The views

| Command                    | Shows                                   |
|----------------------------+-----------------------------------------|
| =:MepOrgAgendaToday=       | today                                   |
| =:MepOrgAgendaWeek=        | the coming week                         |
| =:MepOrgAgendaTodo=        | every open TODO, whatever its date      |
| =:MepOrgAgendaOverdue=     | everything past its deadline            |
| =:MepOrgAgendaSearch=      | search across the agenda files          |

Each collects across *all* your agenda files, which is the point: the
agenda is the view that does not care which file something lives in.

* Agenda files

=:MepOrgAgendaAddFile= adds the current file to the set the agenda scans.

Globs are expanded, so one entry can cover a directory of notes rather than
being listed file by file.
