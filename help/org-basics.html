Org files in mep

What you get

Open a .org file and you get a rendered outline: headings styled by level, emphasis shown, links live, tables aligned. It is still an ordinary text buffer underneath -- every motion, operator and undo works as usual.

:Org and :Text leave a rendered view and show the raw text.

Headings

CommandDoes
:MepOrgCyclecycle this heading's folding
:MepOrgFoldfold
:MepOrgInsertHeadingnew heading at this level
:MepOrgInsertTodoHeadingnew TODO heading
:MepOrgPromote / Demotechange this heading's level
:MepOrgPromoteSubtree / DemoteSubtreemove the whole subtree
:MepOrgNext / Prevnext / previous heading
:MepOrgMatchjump to the matching structure

Narrowing

:MepOrgNarrow restricts the buffer to the subtree under the cursor, so everything -- search, substitute, export -- acts only on that. :MepOrgWiden returns.

This is the tool for working in one section of a large file without the rest getting in the way.

Emphasis

Org's markers work as you would expect: *bold*, /italic/, _underline_, +strikethrough+, =verbatim= and ~code~.

mep leaves the markers visible, as Emacs org-mode does by default, and styles the whole span including them.

Lists

CommandDoes
:MepOrgListNewItemnew item at this level
:MepOrgListIndentindent the item
:MepOrgListOutdentoutdent it
:MepOrgListRenumberrenumber an ordered list
:MepOrgCheckboxtoggle a checkbox

Tables

:MepOrgTableAlign aligns a table's columns on the pipes.

A literal | inside a cell is written \vert or escaped as \|.
