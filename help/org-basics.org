* What you get

Open a =.org= file and you get a rendered outline: headings styled by level,
emphasis shown, links live, tables aligned. It is still an ordinary text
buffer underneath -- every motion, operator and undo works as usual.

=:Org= and =:Text= leave a rendered view and show the raw text.

* Headings

| Command                       | Does                              |
|-------------------------------+-----------------------------------|
| =:MepOrgCycle=                | cycle this heading's folding      |
| =:MepOrgFold=                 | fold                              |
| =:MepOrgInsertHeading=        | new heading at this level         |
| =:MepOrgInsertTodoHeading=    | new TODO heading                  |
| =:MepOrgPromote= / =Demote=   | change this heading's level       |
| =:MepOrgPromoteSubtree= / =DemoteSubtree= | move the whole subtree |
| =:MepOrgNext= / =Prev=        | next / previous heading           |
| =:MepOrgMatch=                | jump to the matching structure    |

* Narrowing

=:MepOrgNarrow= restricts the buffer to the subtree under the cursor, so
everything -- search, substitute, export -- acts only on that. =:MepOrgWiden=
returns.

This is the tool for working in one section of a large file without the rest
getting in the way.

* Emphasis

Org's markers work as you would expect: =*bold*=, =/italic/=, =_underline_=,
=+strikethrough+=, ==verbatim== and =~code~=.

The markers themselves are hidden and the text is styled in their place, so
=*bold*= reads as bold text -- and the line closes up over them rather than
leaving their width behind as a gap. Put the cursor on the line and the
markers come straight back, on their real columns, so there is never a
construct you can see but not edit. =<leader>otm= turns concealment off
altogether, for every construct that uses it -- emphasis, links and table
rules alike. See [[file:org-visuals.html][Org rendering]] for what the
closing-up does inside a table cell.

* Heading sizes

A heading's own leading stars are not drawn. What they say -- how deep the
heading is -- the render already says with size and colour, so concealment
hides them and indents the title one column per level below the first
instead: =* Top= sits at the margin, =** Sub= one column in, and so on. A
folded heading's summary line hides them the same way. =<leader>otm= (markup
concealment) brings them back, as does putting the cursor on the row.

Under those stars, a heading is drawn larger the shallower it is, and in its
own colour by level: =*= largest, =**= a little smaller, =***= smaller
again, =****= and deeper at body size. The top two levels get a line of
space under them as well, which is what gives the outline its shape at a
glance.

=<leader>oth= turns that off and draws every heading at body size.

As with concealment, the heading the cursor is on -- or one inside a
selection -- is drawn at plain body size on the ordinary column grid, so the
caret and the selection always land where you expect.

* Lists

| Command                    | Does                            |
|----------------------------+---------------------------------|
| =:MepOrgListNewItem=       | new item at this level          |
| =:MepOrgListIndent=        | indent the item                 |
| =:MepOrgListOutdent=       | outdent it                      |
| =:MepOrgListRenumber=      | renumber an ordered list        |
| =:MepOrgCheckbox=          | toggle a checkbox               |

* Tables

A table is drawn as a real grid: continuous rules down the columns, a drawn
line in place of each =|---+---|= row, and a tinted header block.

It is realigned on its pipes for you whenever the cursor leaves it, provided
you actually edited it -- typing in a cell never shifts the text under your
caret, and the columns are square again the moment you step out. Reading
through a ragged table changes nothing. =:MepOrgTableAlign= does it on
demand.

A literal =|= inside a cell is written =\vert= or escaped as =\|=.
