Clocking and the Todo panel

Clocking time

CommandDoes
:MepOrgClockInstart the clock on this heading
:MepOrgClockOutstop it
:MepOrgClockTablea table of time clocked

A clock is a CLOCK: line in a :LOGBOOK: drawer under the heading:

:LOGBOOK:
CLOCK: [2026-09-20 Sat 10:00]--[2026-09-20 Sat 11:30] =>  1:30
:END:

Only one clock runs at a time, so clocking in somewhere else stops the previous one.

The Todo panel

<leader>tt (:MepActivityTodoPanel, or the Todo button in the tab bar) lists every keyworded heading in the project's TODO.org and edits it in place.

KeyDoes
aadd a todo -- a new * TODO heading at the end of the file
eopen TODO.org in a float, cursor on this heading
dmark done, or not done again
xdelete it and its subtree, after a confirm
Enterstart or stop this heading's clock
oopen the file
Rre-read it
?list these keys

e is the escape hatch: the panel edits titles and states, but the float gives you the whole heading -- body, properties, logbook -- in a real editable buffer.

lua Copy
mep.activity_todo_file = '~/notes/tasks.org'   -- override the path

The file is the source of truth

The panel does not hold state. Rows and the running clock are re-read from the file on every render, and the panel re-renders whenever TODO.org is edited in a buffer or any buffer is saved.

So edits made in the editor and keys pressed in the panel always agree, and a clock started by typing a CLOCK: line by hand counts exactly the same.

The status-line chip

The clocked-in todo appears at the right of the status line -- green, with its title and a live timer, or a red [No active TODO]. Clicking it toggles the panel.

Marking a clocked-in todo done stops its clock.
