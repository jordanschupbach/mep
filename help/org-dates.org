* Inserting a date

| Command                        | Inserts                            |
|--------------------------------+------------------------------------|
| =:MepOrgTimestamp=             | an active timestamp                |
| =:MepOrgTimestampInactive=     | an inactive one, in square brackets |
| =:MepOrgTimestampRange=        | a range between two dates          |
| =:MepOrgTimestampRepeater=     | add a repeater to a timestamp      |

*Active* timestamps appear in the [[file:org-agenda.html][agenda]]; inactive ones do not. Use an
inactive one to record when something happened without it turning into an
appointment.

* Adjusting one

| Command                      | Does                         |
|------------------------------+------------------------------|
| =:MepOrgTimestampIncr=       | move the date forward        |
| =:MepOrgTimestampDecr=       | move it back                 |
| =:MepOrgTimestampHighlight=  | highlight timestamps in view |

* Scheduling a task

| Command               | Sets                                        |
|-----------------------+---------------------------------------------|
| =:MepOrgScheduled=    | =SCHEDULED:= -- when you intend to start    |
| =:MepOrgDeadline=     | =DEADLINE:= -- when it must be done         |

The distinction is worth keeping: scheduled controls when a task starts
showing up in your agenda, deadline controls when it becomes urgent.
