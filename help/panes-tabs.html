Panes and tabs

The hierarchy

Panes live in tabs, tabs live in workspaces, workspaces live in projects. Each tab has its own independent split layout, so switching tabs swaps the whole arrangement of panes.

Splitting

Command / keyDoes
:split [file]split horizontally
:vsplit [file]split vertically
Ctrl-W ssplit horizontally
Ctrl-W vsplit vertically
Ctrl-W cclose this pane
:closeclose this pane

With no file given, the new pane shows the same buffer. Two panes on one buffer share everything about it, including undo history -- there is only one set of contents, so there is only one thing to undo.

Moving between panes

KeyMoves focus
Ctrl-W h j k lleft / down / up / right
Ctrl-W wto the next pane, in order
Ctrl-W Wto the previous pane

Ctrl-W hjkl is directional, not cyclic: it picks the pane with the most overlap along the perpendicular axis and then the nearest one, the same heuristic tmux and i3 use. If there is no pane that way, nothing happens.

The mod1 layer has the same directional moves on mod1+hjkl, plus resizing and rearranging. See The mod1 layer.

Tabs

Buffer tabs within a pane

A pane can hold several buffers as a tab strip along its top, which is different from window tabs: these are buffers sharing one pane, not separate layouts.

Each pane header ends with three buttons -- | splits it vertically, _ splits it horizontally, and x closes the visible buffer, closing the pane once it is empty.

From the keyboard, mod1+d removes the pane's active buffer tab, and mod1+Ctrl+hjkl moves it into the neighbouring pane that way.

The tab bar

One row across the top:

[project] [ws1] [ws2*] | ● ○ + x

The project name, then one label per workspace -- the active one highlighted, * when it has unsaved buffers, dimmed with ... while its worktree is still being created -- then the active workspace's tabs as circles with new and close buttons.

Clicking a workspace label switches to it, middle-clicking closes it, and hovering shows its directory and branch. Clicking the project name opens the project switcher.

Docked at the right are participant chips, three search buttons (fuzzy find in this buffer, project-wide live grep, and the buffer picker) and a row of sidebar toggles: Files, Git, Symbols, Structure, Todo, Tests, Notifications and AI Agents. Each is lit while its panel is open.

Dragging a file onto a pane

A row in the file tree or the git status panel can be dragged straight onto a pane. A drop-zone pinwheel lights up under the pointer: drop in the centre to open the file in that pane, or on an edge to split the pane that way and open it in the new half.
