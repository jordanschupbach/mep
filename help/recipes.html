Configuration recipes

A starting init.lua

lua Copy
mep.colorscheme('everforest-dark')
mep.cmd('set textwidth=88')
mep.opt.tab_terminal_share = 0.35

Turn Copilot off

lua Copy
mep.copilot_enabled = false          -- entirely; no server is started
mep.copilot_filetypes['md'] = false  -- or just for markdown

Add a formatter

lua Copy
mep.format_languages.js = {'prettier', '--stdin-filepath', '{}'}
mep.format_languages.ts = mep.format_languages.js
mep.format_languages.tsx = mep.format_languages.js

Entries are keyed by bare extension, so every extension needs its own key.

Add a notebook kernel

lua Copy
table.insert(mep.opt.notebook_kernels, {
  name = 'deno', display_name = 'Deno', language = 'js',
  mode = 'script', command = {'deno', 'run', '-'},
})

Point a language UI mode at a virtualenv

lua Copy
mep.opt.py_ui_cmd = {'.venv/bin/python', '-i', '-q'}

Relocate git worktrees

lua Copy
mep.opt.worktree_dir = '~/worktrees'   -- absolute, or relative to the project
mep.opt.workspace_git_dirty = true     -- mark dirty workspaces with '+'

A stage-aware git gutter

lua Copy
mep.git_gutter_base = 'index'    -- like gitsigns; default is HEAD
mep.git_gutter_line_hl = true    -- tint the whole changed line

A custom statusline

lua Copy
mep.set_statusline(function()
  local name = mep.filename()
  if name == '' then name = '[No Name]' end
  local git = mep.git_gutter_summary()
  return name .. (git ~= '' and ('  ' .. git) or '')
end)

The Ln/Col readout and the chips are drawn either way -- this replaces the text, not the whole row.

A sidebar of your own

lua Copy
local id = mep.sidebar_create('Notes', 'right', 30)
mep.sidebar_set_sections(id, {{
  id = 'main', title = 'Notes', collapsed = false,
  widgets = {
    {id = 'a', text = 'Open TODO', on_click = function() mep.open('TODO.org') end},
  },
}})
mep.sidebar_set_help(id, {{'Enter', 'open the item'}})
mep.leader_map('xn', 'Notes panel', function() mep.sidebar_toggle(id) end)

Run something on every save

lua Copy
mep.on_buffer_saved(function()
  if (mep.filename() or ''):match('%.py$') then mep.format_buffer() end
end)

A project-local config

lua Copy
-- at the end of init.lua
local per_project = mep.getcwd() .. '/.mep.lua'
local f = io.open(per_project)
if f then f:close() mep.cmd('source ' .. per_project) end

mep.on_workspace_changed(fn) re-runs this when you switch workspaces.
