Spreadsheets

Opening

.xlsx, .ods and .csv open as a grid: a real spreadsheet view with rows, columns and cell selection.

Opening a sheet fits each column to its contents, up to a limit, so one long notes column does not push the rest off screen. A value too long for its column ends in …, which means there is more: widen the column, or wrap the row (see below). A newline inside a value shows as ⏎ until the row is tall enough to show the lines themselves.

If the first row is a row of column names -- all text, no blanks, no repeats -- it is frozen and drawn as a header: it stays on screen while the data scrolls, and sorting and filtering leave it where it is. :MepSheetUnfreeze puts it back among the data.

Moving and editing

The usual motions move between cells.

Editing happens in the cell itself: it opens with a caret in it, and what you type appears there (the formula bar above mirrors it). A value longer than its column spills over the cells to its right while you type, and scrolls once it reaches the edge of the pane.

Yanking and pasting

y copies from the grid into the unnamed register and the system clipboard, so what you yank can be pasted into a text buffer, a CSV's own text view or another program.

KeyYanks
yy or Ythe cursor's row, as a CSV record
ylthe cursor's cell, as its plain value
y in Visualthe selected block, as CSV records
x / dclear the cell (or the Visual block) and yank what was there

Records are written exactly as :w would write them: values as the file spells them, fields quoted when they hold a comma, a quote or a newline, and empty cells kept so a block stays square. They are yanked as whole lines, so p in a text buffer adds them below the cursor line. In a sorted or filtered view a Visual block is the rows as you see them, in that order -- never a row the filter hides.

p (or P) pastes at the cursor cell. Records -- anything yanked as lines -- fill a block of cells down and to the right, empty fields clearing their cells; any other text goes into the cursor's cell whole, so a pasted "Smith, John" stays one value. u undoes a paste.

Zoom

+ and - make the grid bigger and smaller -- cells and text together, so nothing clips -- and = puts it back to 100%. Ctrl with the mouse wheel does the same. The zoom belongs to the pane, so switching between a workbook's sheets keeps it. :MepSheetZoom in|out|reset|<percent> sets it from the command line, and <leader>Sz resets it.

Column widths and row heights

The keys that resize a pane size a cell in a spreadsheet: Alt-Shift-h and Alt-Shift-l narrow and widen the cursor's column, Alt-Shift-k and Alt-Shift-j make its row shorter and taller. Hold them to keep going. In Visual mode they size every selected column or row together, and they work while a cell is being edited, without typing anything into it. (To resize the pane a sheet is in, drag its border.)

Alt-Left and Alt-Right / Alt-Up and Alt-Down do the same, and with Shift held as well they size every column or row at once.

With the mouse, drag the edge of a column header -- or of a row number -- to size it. Double-click a column's edge to fit it to its contents, and a row's edge to fit the row to its wrapped text (double-click again to put it back to one line).

A row taller than one line wraps its values to fill it, so making a row taller is the other way to read a long value. :MepSheetWrap (<leader>Sr) does it for every row at once: each grows to fit its longest value at the current widths, and running it again puts them all back to one line.

CommandDoes

<leader>Saautofit this column

Autofit measures the widest value it can find, sampling the first few thousand rows of a very long file rather than stalling on all of them; it says so in the status line when it had to sample.

Sorting

Sorting is a view: it changes the order rows are shown in and nothing else. No cell moves, no formula is rewritten, u is not involved, and :w still writes the file in its original order. The row numbers down the left stay with their rows, so a sorted sheet shows you exactly which rows you are looking at.

Text sorts case-insensitively, numbers sort as numbers, numbers come before text in a mixed column, and blanks go last whichever direction you sort in. Equal values keep their original order.

CommandDoes
:MepSheetSort [col] [asc\vert desc] [text\vert num\vert auto]sort by a column
:MepSheetSortClearback to the file's own order
<leader>Ss / <leader>SSsort this column up / down
<leader>Sn / <leader>SNsort this column numerically, up / down
<leader>Scclear the sort

A column argument can be a letter (B, AB) or a 1-based number; leave it out and the cursor's column is used.

Making it permanent

:MepSheetApply rewrites the cells into the order you are looking at, so :w saves it. That one is an edit -- u undoes it. If a filter is on, the rows it is hiding are kept, after the visible ones, rather than dropped. If moving a row would move a formula with it, the command stops and says so, because nothing here rewrites the references inside a formula; :MepSheetApply! goes ahead anyway. <leader>Sp is the same thing.

Filtering

Filters hide rows. Like sorting they are a view: the file is untouched until you apply the order. The formula bar shows how many rows survived -- "12 of 4310 rows" -- so a filtered sheet never looks like the whole file.

: :MepSheetFilter [col] <op> [value]

where <op> is one of =, !, ~ (contains), !~ (does not contain), >, <, empty, nonempty, or re (a regular expression). Text matching ignores case. > and < compare as numbers when you give them a number, so :MepSheetFilter C > 100 does not drag text values in with it, and as text otherwise.

CommandDoes
:MepSheetFilterClear [col]clear one column's filter, or all of them
<leader>Sfprompt for a filter on this column
<leader>SFclear every filter

One filter per column; filters on different columns all have to pass.

The column menu

Click a column's letter to open a menu on it: sort, autofit, freeze, statistics, and a list of the column's values with a tick box each. Tick the ones you want and choose "Apply ticked values as a filter". On a column with more distinct values than fit, the list scrolls, and says how many it is showing -- use <leader>Sf to filter by text instead. Clicking anywhere else closes the menu.

The column header also shows what is on: ^ or v for the sort direction, and * on a filtered column.

Freezing headers

:MepSheetFreeze [rows] [cols] pins that many leading rows and columns so they stay put while the rest scrolls. With no arguments it freezes everything above and left of the cursor, which is the quick way to pin a header row. Frozen rows are also held out of the sorting and filtering -- a header is a label, not data. :MepSheetUnfreeze and <leader>SH undo it; <leader>Sh freezes at the cursor.

Statistics

<leader>St or :MepSheetStats [col] reports the column's row count, how many are non-empty, how many distinct values it holds, and -- for the numbers in it -- the sum, mean, minimum and maximum. It describes what is currently visible, so a filtered view reports the filtered numbers. In Visual mode it describes the selected rows instead.

Finding

/ prompts for text and jumps to the next cell containing it; n and N go to the next and previous match, wrapping around. It honours :set ignorecase, searches the values as shown (so a formula is found by its result), and never lands on a row a filter is hiding. :MepSheetFind <text> and <leader>S/ are the same thing.

Formulas

mep has its own formula engine, so a cell containing SUM(A1:A10) is evaluated rather than shown as text. Formulas recalculate as their inputs change.

Saving

:w writes back in the original format -- .xlsx stays .xlsx. The view -- zoom, widths, sort, filters, frozen headers -- is not part of the file and is not saved with it.

From Lua

mep.sheet_sort(col, kind, descending), mep.sheet_sort_clear(), mep.sheet_filter(col, op, value), mep.sheet_filter_clear(col), mep.sheet_freeze(rows, cols), mep.sheet_zoom(factor), mep.sheet_zoom_reset(), mep.sheet_autofit(col), mep.sheet_col_width(col, px), mep.sheet_row_height(row, px), mep.sheet_fit_rows(row), mep.sheet_wrap(), mep.sheet_toggle_text(), mep.sheet_stats(col), mep.sheet_find(text, forward), mep.sheet_apply(), mep.sheet_cell(row, col) and mep.sheet_info(), which returns the cursor, the zoom, the sort, the filters, the row counts and the display order in one table. Rows and columns are 1-based.

CSV

A .csv opens in the same grid, which makes it a comfortable way to read data files that are painful as text. Numbers are shown as the file spells them (19.00, not 19), and saving writes every value back the way it was read, in the file's own line endings -- only a formula, which CSV cannot hold, is saved as its result.

Grid or plain text

:MepSheetText shows the same buffer as its plain text, each column in its own colour, and :MepSheetGrid shows the grid again; :MepSheetToggle and <leader>Sv switch between them. Edits made in either view carry over to the other unsaved, and :w works from both. The grid's widths, frozen rows, sort, filters and zoom are kept while you are in the text.
