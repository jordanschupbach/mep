#+TITLE: Keyboard shortcuts

* Help

- =<leader>hh=: open the help workspace on its introduction page.
- Click a link in a help page to open the linked page.
- =f= in a help page: label every visible link with a letter; type a
  label to follow that link, or press =Esc= to cancel.

* Everyday movement

Use =h=, =j=, =k=, and =l= in Normal mode to move.  Use =i= to enter Insert
mode and =Esc= to return to Normal mode.

See [[file:editing.html][Editing basics]] for a short overview.
