Snippets

Expanding one

Type a trigger and press Tab. Triggers also appear in the completion popup, so you do not have to remember them -- start typing and look. In an Org, LaTeX or Markdown note, Tab never expands a word; accept the trigger from the popup instead (Ctrl-Y), see Note-taking.

<leader>yy (:MepSnippets) opens a picker of every snippet available for the current filetype. Its preview shows the highlighted snippet as it would be inserted, syntax-coloured, with each field's default text tinted and a list of the fields in the order Tab visits them (a choice field lists its options). A snippet picked there goes in at the cursor; nothing before the cursor is replaced.

Fields

A snippet can place the cursor in several spots in turn. The cursor lands on the first field with its default text selected: typing replaces it, Backspace clears it, and moving on without typing keeps it.

KeyDoes
Tabnext field; from the last, past the snippet
Shift-Tabprevious field
Ctrl-J / Ctrl-Kcycle a choice field
:MepSnippetNextjump to the next field
:MepSnippetPrevjump to the previous one

Fields follow the text: type as much as you like in one and the next is still where it belongs. A snippet expanded inside another one's field is walked first, and its end leads back to the outer field. Tab works only while the cursor is inside a snippet; elsewhere it indents as usual.

Syntax inside a snippet body:

FormMeans
$1, $2fields, visited in order
${1:default}a field pre-filled with text (braces may nest inside)
$1 againa mirror: copies field 1 as it is typed
$0where the cursor finishes (default: the very end)
\$a literal dollar sign

A choice field is written ${1|a,b,c|}: it starts as a, and Ctrl-J / Ctrl-K cycle it. Lines after the first are indented like the line the trigger was on.

What ships

Curated sets for c, cpp, go, lua, py, r, rs, sql, nix and envrc.

The py set includes print, which expands to print() with the cursor between the parentheses.

Some are pieces that go inside a statement rather than whole statements: join (a choice of JOIN / LEFT JOIN / INNER JOIN), ord, lim, case, win (ROW_NUMBER / RANK / DENSE_RANK OVER (...)), exists, ret (RETURNING), and the column definitions col, ref and fk. A *dev fragment is a plain list of toolchain packages: pydev (uv, ruff, pyright), cdev, cppdev, rustdev, godev, nodedev, javadev, zigdev, ocamldev, hsdev and luadev. hook adds a shellHook, and unfree the import nixpkgs line that allows unfree packages.

Inside a fragment's library list, a library is its nixpkgs name without the set's prefix: what nix search nixpkgs python3Packages.scipy finds is written scipy, and rPackages.tidyr is written tidyr.

Adding your own

lua Copy
mep.snippets.py = mep.snippets.py or {}
mep.snippets.py['main'] = {
  'def main() -> None:',
  '    ${1:pass}',
  '',
  'if __name__ == "__main__":',
  '    main()',
}

mep.snippets is keyed by bare file extension, and each entry is an array of lines. Because it is an ordinary table, a set can be extended, replaced or removed from init.lua.
