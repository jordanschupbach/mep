* Expanding one

Type a trigger and press =Tab=. Triggers also appear in the [[file:completion.html][completion]]
popup, so you do not have to remember them -- start typing and look. In an
Org, LaTeX or Markdown note, =Tab= never expands a word; accept the trigger
from the popup instead (=Ctrl-Y=), see [[file:org-notes.html][Note-taking]].

=<leader>yy= (=:MepSnippets=) opens a picker of every snippet available for
the current filetype.

* Fields

A snippet can place the cursor in several spots in turn. The cursor lands
on the first field with its default text selected: typing replaces it,
=Backspace= clears it, and moving on without typing keeps it.

| Key                    | Does                                          |
|------------------------+-----------------------------------------------|
| =Tab=                  | next field; from the last, past the snippet   |
| =Shift-Tab=            | previous field                                |
| =Ctrl-J= / =Ctrl-K=    | cycle a choice field                          |
| =:MepSnippetNext=      | jump to the next field                        |
| =:MepSnippetPrev=      | jump to the previous one                      |

Fields follow the text: type as much as you like in one and the next is
still where it belongs. A snippet expanded inside another one's field is
walked first, and its end leads back to the outer field. =Tab= works only
while the cursor is inside a snippet; elsewhere it indents as usual.

Syntax inside a snippet body:

| Form            | Means                                                  |
|-----------------+--------------------------------------------------------|
| =$1=, =$2=      | fields, visited in order                               |
| =${1:default}=  | a field pre-filled with text (braces may nest inside)  |
| =$1= again      | a mirror: copies field 1 as it is typed                |
| =$0=            | where the cursor finishes (default: the very end)      |
| =\$=            | a literal dollar sign                                  |

A choice field is written =${1|a,b,c|}=: it starts as =a=, and =Ctrl-J= /
=Ctrl-K= cycle it. Lines after the first are indented like the line the
trigger was on.

* What ships

Curated sets for =c=, =cpp=, =go=, =lua=, =py=, =rs=, =nix= and =envrc=.

The =py= set includes =print=, which expands to =print()= with the cursor
between the parentheses.

* Python: numpy and matplotlib

The =py= set also carries a scientific-Python family. Every trigger starts
with =np= or =plt=, so typing either prefix lists the whole family in the
completion popup. The bodies assume the usual aliases, which =npimp=,
=pltimp= and =sciimp= insert.

| Trigger       | Inserts                                            |
|---------------+----------------------------------------------------|
| =npimp=       | =import numpy as np=                               |
| =pltimp=      | =import matplotlib.pyplot as plt=                  |
| =sciimp=      | both imports                                       |
| =nparr=       | a 1-D =np.array=                                   |
| =nparr2=      | a 2-D =np.array=, one row per line                 |
| =npzeros= =npones= =npfull= =npeye= | the matching constructor     |
| =nparange= =nplinspace= | a range of values                        |
| =npmesh=      | =np.meshgrid=                                      |
| =nprng=       | =np.random.seed(seed)=                             |
| =npnormal= =npuniform= | =np.random.normal= / =np.random.uniform= samples |
| =npload= =npsave= | =np.loadtxt= / =np.savetxt=                    |
| =pltline=     | =plt.plot= with axis labels and =plt.show()=       |
| =pltscatter=  | a scatter plot, likewise                           |
| =plthist=     | a histogram, likewise                              |
| =pltbar=      | a bar chart                                        |
| =pltimshow=   | an image with a colour bar                         |
| =pltcontour=  | a filled contour with a colour bar                 |
| =pltfig=      | the =fig, ax = plt.subplots()= form, one axis      |
| =pltgrid=     | a grid of axes, looping over =axes.ravel()=        |
| =pltlabels=   | xlabel, ylabel, title, legend                      |
| =pltsave=     | =plt.savefig= at 150 dpi                           |
| =pltshow=     | =plt.show()=                                       |

Each plot snippet (=pltline= through =pltgrid=) is a complete, runnable
script: the imports, some example data, the plot call, labels and
=plt.show()=. Expand one into an empty file and run it as is, or tab
through the tabstops to swap in your own data and labels.

* Adding your own

#+begin_src lua
mep.snippets.py = mep.snippets.py or {}
mep.snippets.py['main'] = {
  'def main() -> None:',
  '    ${1:pass}',
  '',
  'if __name__ == "__main__":',
  '    main()',
}
#+end_src

=mep.snippets= is keyed by bare file extension, and each entry is an array
of lines. Because it is an ordinary table, a set can be extended, replaced
or removed from =init.lua=.
