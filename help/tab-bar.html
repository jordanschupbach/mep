The tab bar

One row, four jobs

[project] [ws1] [ws2*] | ● ○ + x            chips  search  panels

Reading left to right: which project you are in, which workspaces it has, which tabs the active workspace has, and then -- docked right -- who else is here, the searches, and the panel toggles.

The project label

The leftmost item is the active project's name. Clicking it opens the loaded-projects switcher, the same thing <leader>pp opens.

Workspace labels

One label per workspace in the project.

You seeIt means
highlightedthis is the active workspace
* after a namethat workspace has unsaved buffers
dimmed, ...its git worktree is still being created
+ after a nameuncommitted changes (only with workspace_git_dirty)
ActionDoes
clickswitch to that workspace
middle-clickclose it
hovershow its directory and branch

The * marker is worth watching: it is how you notice unsaved work in a workspace you are not currently looking at, which is exactly the work :qa will refuse to discard.

Tabs

The active workspace's tabs, drawn as circles -- filled for the current one -- followed by a + to add a tab and an x to close the current one.

Each tab has its own split layout. See Panes and tabs.

Docked right

Participant chips show anyone else connected: other humans in a collaboration session, and AI agents running in this window. Clicking a chip jumps to that participant's cursor.

Three search buttons, which are the same pickers as:

ButtonKey
fuzzy find in this buffer<leader>/
project-wide live grep<leader>pr
open buffers<leader>bb

Panel toggles for Files, Git, Symbols, Structure, Todo, Tests, Notifications and AI Agents. Each is lit while its panel is open; click to open or close.

A speech-to-text microphone indicator appears here while live transcription is recording.
