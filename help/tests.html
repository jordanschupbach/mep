Tests

Run this file's tests

gt (:MepLangTest) works out how to test the file you are looking at and runs it in this tab's terminal.

It saves the buffer first when it is modified -- a test run against a stale copy on disk is worse than useless -- and reports the command it chose as a toast, which is the only feedback when the terminal is off screen.

FiletypeRuns
.goGo's test runner
.pythe configured Python test runner
.r, .RR's test tooling
.c, .cpp, headersthe project's build-directory test target
.rsCargo's test runner
lua Copy
mep.opt.lang_test_python = {'pytest', '-q'}
mep.opt.lang_test_build_dirs = {'build', 'build/native'}

If mep cannot work out a runner for the filetype, it says so in one line rather than guessing.

The Tests panel

<leader>tT (:MepActivityTestPanel) opens the test sidebar; :MepActivityTestRun runs from it.

A failing test's location is a row you can press Enter on to jump straight to the line, so the loop is: run, read the failure, jump, fix.

mep.activity_test_failure_lines() exposes the parsed failure locations to Lua.
