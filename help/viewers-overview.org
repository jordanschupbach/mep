* Everything in a pane

mep decides how to present a file from its extension. Each viewer is an
ordinary pane, so splits, tabs, workspaces and the theme all apply.

* Two things that surprise people

*An HTML file opens as source.* =:e page.html= gives you the markup, because
that is usually what you want from a file you are editing. To render it, use
=:Browse page.html=, or open it through a link or the file tree.

*Everything is editable except where noted.* The PDF, 3D and image views are
not read-only previews -- images have a full editor behind =e=, 3D scenes
have a scripting API, and spreadsheets and office documents write back.

* Theming

Rendered documents are re-tinted to the active theme by default, rather than
showing a white page inside a dark editor. The pane header says
=[theme, Ctrl-R]= when it is doing this, and =Ctrl-R= switches to the
document's own colours.
