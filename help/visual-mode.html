Visual modes

Select, then act

Visual mode inverts the usual order: instead of naming a range up front (d2w), you select it and watch it highlight, then press the operator. Useful whenever the range is easier to see than to describe.

KeySelects by
vcharacter
Vwhole lines
Ctrl-Vrectangle

Press the same key again, or Esc, to leave. Any motion extends the selection, and a text object sets it outright: viw selects a word, vi( the inside of a parenthesised group.

Acting on a selection

Every operator works: d deletes it, y yanks it, c changes it, gu and gU change its case, gq reflows it, ~ toggles case.

> and < indent, and they keep the selection active -- press > three times to indent three steps, matching Vim.

Moving the other end

o swaps the cursor to the opposite end of the selection. Useful when you have selected too much in one direction and want to adjust the other end without starting over.

Visual Block

Ctrl-V selects a rectangle, which is what you want for columns.

KeyIn Visual Block
ddelete the rectangle
yyank the rectangle
Iinsert on every row of the block at once
Aappend on every row of the block at once
$make the right edge ragged -- each row's own real end

$ before A is the idiom for appending to the end of every line in a range regardless of how long each one is.

Reselecting

gv restores the last Visual selection, including its mode. Handy after an operation that dropped the selection, or to repeat an action on the same region.

A gap worth knowing

Changes made from Visual mode are not currently captured by . or by macro recording. Both work for Normal-mode changes; a Visual-mode change is simply not recorded. Where repetition matters, prefer the operator-plus-motion form.
