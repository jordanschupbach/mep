#+TITLE: Writing help pages

* Add a topic

Create an exported =.html= page in the =help/= directory. Its HTML =<title>=
becomes the label in the Help sidebar.

* Link pages

Use relative HTML links, for example:

#+begin_example
[[file:editing.html][Editing basics]]
#+end_example

Click a link to follow it. Link back to [[file:intro.html][mep Help]] when a
topic needs a natural return path.
