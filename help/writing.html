Writing prose in mep

Setting up

A few options turn a code editor into a comfortable place to write:

lua Copy
-- in ~/.config/mep/init.lua, or via :set for one session
mep.cmd('set textwidth=72')
mep.cmd('set nonumber norelativenumber')

Then :MepZen strips the interface back to the text -- no tab bar, no sidebars, no status line. Run it again to bring them back.

Reflowing

gq wraps to textwidth. The forms worth knowing:

KeysReflows
gqqthis line's paragraph
gqapthe paragraph around the cursor
gqGeverything to the end of the file

In Visual mode, gq reflows the selection.

Spelling

<leader>zt turns spell checking on; <leader>zn and <leader>zp move between misspellings; <leader>zf fixes one and <leader>zg adds a word to your dictionary. See Spell checking.

Keeping time

The Pomodoro chip on the status line runs 25 minutes of work and 5 of break; click it to start.

For tracking effort against a piece of work, clock it: <leader>tt opens the Todo panel, Enter starts a heading's clock, and the status line shows a live timer. See Clocking and the Todo panel.

Getting it out

An Org document exports to HTML, Markdown, plain text, PDF or ODT -- see Exporting. Markdown has its own page.
