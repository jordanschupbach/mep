# What mep may link and run (plans/DEPENDENCY_REMOVAL_PLAN.md), checked by
# scripts/deps-audit.sh (`just deps-audit`, part of `just test`).
#
#   lib  <shell glob on the library path>  <kind>  <note>
#   prog <shell glob on the program name>  <kind>  <note>
#
# kind:
#   os         part of the operating system: always fine
#   kept       a deliberate exception (the :Browser web engine)
#   user       the user's own toolchain, run for their code or by their choice
#   optional   an alternative backend the user picks; mep has an in-house default
#   temporary  a dependency still to be replaced -- the note names the phase
#
# Anything the audit finds that matches no line here fails it: add a line
# only after deciding which kind it is.
