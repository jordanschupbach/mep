assets/spell/en_US.words is derived from SCOWL (Spell Checker Oriented Word
Lists), the same word data GNU Aspell's English dictionary (aspell-dict-en)
is built from. It was produced by dumping the aspell en_US master word list
(`aspell -d en_US dump master`), filtering to letter/apostrophe/hyphen tokens,
and sorting. No aspell code or compiled data is bundled -- only the plain word
list, used by mep's own dependency-free checker in src/spell.cpp.
