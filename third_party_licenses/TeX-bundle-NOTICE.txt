share/mep/tex/tex-bundle.mtb -- mep-tex's TeX bundle -- is a collection of
files from TeX Live, packed by tools/tex_bundle.py (see nix/tex-bundle.nix
for the packages chosen). It is data that mep-tex reads; nothing in it is
compiled into mep.

The files are redistributed unmodified. Each keeps the licence of the TeX
Live package it comes from; the bundle itself carries the full list, by
package, in MANIFEST.json and LICENSES.txt (unpacked into
~/.cache/mep/tex/bundle-*/ on first use). In summary:

  * Most packages -- the LaTeX kernel and its required packages, amsmath,
    hyperref, geometry, xcolor, tcolorbox, standalone, the tools bundle and
    the rest -- are under the LaTeX Project Public License (LPPL 1.3c, a few
    1.0/1.2). https://www.latex-project.org/lppl/
  * Computer Modern (cm) and plain TeX: Donald Knuth's terms (free to use and
    redistribute unmodified).
  * AMS fonts (amsfonts): SIL Open Font License 1.1.
  * Latin Modern (lm): GUST Font License (an LPPL variant).
  * pgf/TikZ and beamer: dual LPPL 1.3c / GNU GPL 2 (their documentation,
    not included, is under the GNU FDL).
  * preview: GNU GPL 3. translator, zapfding, symbol, and the configuration
    files of the pdftex/dvipdfmx/enctex packages: GNU GPL. Being TeX macro
    and configuration files, these are their own source, shipped unchanged.
  * psnfss's PostScript fonts -- URW's free versions of the PostScript 35
    (times, helvetic, courier, palatino, avantgar, bookman, ncntrsbk,
    zapfchan) and mathpazo: GNU GPL, with the fonts' own embedding terms;
    fpl (Palatino small caps and old-style figures): GNU GPL 2 / LPPL 1.3c;
    Bitstream Charter, Adobe Utopia and rsfs: their own free licences.
    Fonts read by mep-tex and embedded in the PDFs it writes, as pdfTeX
    does; shipped unchanged.
  * Hyphenation patterns (hyph-utf8, hyphen-english): permissive terms
    stated in each pattern file.
  * MIT and public-domain packages: as stated in each.

mep-fallback.map (a font map naming which Latin Modern font draws each EC
font) is generated by tools/tex_bundle.py and is part of mep (MIT).
