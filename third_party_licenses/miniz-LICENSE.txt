miniz v3.1.2 -- https://github.com/richgel999/miniz
Fetched via CMake FetchContent (see CMakeLists.txt's `miniz` block) as the
pre-amalgamated single miniz.c/miniz.h pair from the upstream GitHub
Release asset (not the modular git-repo source tree) for the DOCX/ODT ZIP
container reading and writing (both formats are ZIP archives of XML parts)
in src/office_doc.cpp -- specifically mz_zip_reader_*/mz_zip_writer_*,
including mz_zip_writer_add_from_zip_reader for structurally-correct
round-trip saves. Not git-committed source -- built at configure time, the
same way raylib/lua/pugixml are.
