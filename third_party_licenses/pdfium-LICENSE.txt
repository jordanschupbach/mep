PDFium -- https://pdfium.googlesource.com/pdfium/
Used (as a prebuilt shared library, not vendored source) for src/pdf_doc.cpp's
PDF-viewer backend. Fetched at CMake configure time via FetchContent from
github.com/bblanchon/pdfium-binaries, a project that publishes Google's own
PDFium build as ready-to-link release archives -- see CMakeLists.txt's
PDFIUM_ASSET/PDFIUM_HASH block. Not vendored as source because there is no
CMake build for PDFium itself (upstream builds it with Google's own GN/ninja
toolchain); the fetched archive's own licenses/ directory (under
build/*/_deps/pdfium-src/licenses/ once fetched) has the full text of every
license summarized below.
